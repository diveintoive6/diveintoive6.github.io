## 1. 파일 입출력 객체의 생성 (`open()`)

`open()` 함수는 파일을 저장하거나 읽을 수 있는 기능을 제공하는 파일 객체를 리턴합니다.
> **기본 구조:** `객체이름 = open(파일경로, 읽기모드, encoding='인코딩')`
> * 지정된 파일이 존재하지 않을 경우 새로 생성하고, 존재할 경우 해당 파일을 가져옵니다.

### ① 읽기 모드 종류
* `r`: 텍스트 읽기
* `w`: 텍스트 새로 쓰기 (**기존 내용 삭제**)
* `a`: 텍스트 이어 쓰기 (**기존 내용 유지**)
* `rb`: 바이너리(이미지 파일 등) 읽기
* `wb`: 바이너리 새로 쓰기
* `ab`: 바이너리 이어 쓰기

### ② 인코딩 종류 (파이썬은 기본적으로 `utf-8` 사용)
* `euc-kr`: 한국어 전용 (MS-Office 등)
* `utf-8`: 다국어 지원 (VSCode, 메모장 등)

---

## 2. 경로 (Path) 의 이해

파일 시스템 내에서 특정 파일이나 폴더의 위치를 나타내는 양식입니다.

* **절대경로:** 작업 중인 위치에 상관없이 어디서든지 같은 문자열로 접근할 수 있는 경로 형태입니다. 파일 시스템의 최상위 위치부터 목적한 위치까지 경로를 모두 나열합니다.
  * *예시:* `/Users/abcd/a.ipynb` (Windows의 경우 `C:\Users\abcd\a.ipynb`)
* **상대경로:** 현재 작업 중인 폴더를 기준으로 탐색합니다. 현재 위치는 `.`, 1단계 상위 위치는 `..`으로 표현합니다.

## 3. 파일 사용 후 정리와 `with`문 자동화

일반적으로 `open()`을 사용해 파일을 열었다면 작업 완료 후 반드시 **`close()`**를 호출하여 파일 자원을 반납해야 합니다. (그렇지 않으면 프로세스가 파일을 계속 점유하게 됩니다.)

### 전통적인 파일 처리 방식
```python
file = open("test.txt", "w", encoding="utf-8")
file.write("안녕하세요!")
file.close()  # 수동으로 닫아주어야 함

```

### `with`문을 사용한 `close()` 처리 자동화 (추천 ⭐)

`with`문은 객체의 유효성 범위를 제한하여, 블록을 벗어날 때 **`close()` 처리를 자동으로 수행**해 줍니다.

```python
# 파일 쓰기 예시
with open("test.txt", "w", encoding="utf-8") as file:
    file.write("안녕하세요, 파이썬 파일 입출력입니다!")

# 파일 읽기 예시
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

```

## 4. 파일 읽기 메서드 및 CSV 처리

### 여러 줄 읽어오기 (`readlines`)

* `read()`: 파일 전체 내용을 하나의 큰 문자열로 읽어옵니다.
* **`readlines()`**: 파일의 복수 줄을 각각 읽어와 **리스트** 형태로 반환합니다.

### CSV 파일 읽기

* 전통적인 방식으로는 `with open()`을 호출한 뒤 `readlines()`를 통해 텍스트를 읽어와 파싱(Parsing)해야 합니다.
* 다만, 데이터 분석 라이브러리인 **Pandas**의 `read_csv()` 기능을 배운 이후부터는 굳이 복잡하게 수동으로 처리할 필요 없이 간편하게 불러올 수 있게 됩니다.

```python
# 전통적인 CSV 읽기 방식 예시
with open("data.csv", "r", encoding="utf-8") as file:
    lines = file.readlines()
    for line in lines:
        print(line.strip())

```
