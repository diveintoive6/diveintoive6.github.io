## 1. SQL 함수(Function) 개요

SQL 함수는 데이터를 가공하거나 계산하는 데 사용하는 도구입니다.
- **주요 목적**: 조회 결과의 요약, 데이터의 변환(가공), 의미 있는 정보의 추출
- **특징**: 복잡한 계산을 간단한 명령으로 처리할 수 있게 해줍니다.

### SQL 함수의 종류
1. **단일 행 함수 (Single-Row Functions)**: 하나의 행(row)에 대해 하나의 결과값을 반환합니다. (각 행을 독립적으로 처리)
   - *예시*: `UPPER()`, `ROUND()`, `LENGTH()` 등
2. **집계 함수 (Aggregate Functions)**: 여러 행(row)의 값을 하나의 결과로 요약합니다.
   - *예시*: `SUM()`, `AVG()`, `MAX()` 등

> 💡 **참고**: 이번 포스팅에서는 **단일 행 함수**만 다룹니다. 집계 함수는 다음 파트에서 다룰 예정입니다.

### 단일 행 함수의 유형
| 구분 | 설명 | 예시 |
| :--- | :--- | :--- |
| **문자열 함수** | 문자열을 변경하거나 분석 | `UPPER()`, `LOWER()`, `LENGTH()`, `SUBSTR()` |
| **숫자 함수** | 숫자를 계산하거나 반올림 | `ROUND()`, `CEIL()`, `FLOOR()`, `MOD()` |
| **조건 및 NULL 처리 함수** | 조건이나 NULL값의 처리 등 | `IF()`, `IFNULL()` |
| **날짜 함수** | 날짜를 계산하거나 형식을 변환함 | `NOW()`, `DATE_ADD()`, `DATE_FORMAT()` |
| **형변환 함수** | 데이터 타입을 변경함 | `CAST()`, `CONVERT()` |

## 2. 문자열 함수 (String Functions) & 숫자 함수 (Numeric Functions) 요약

### 주요 문자열 함수
| 함수명 | 기능 | 예시 및 결과 |
| :--- | :--- | :--- |
| **UPPER(str) / LOWER(str)** | 대소문자 변환 | `upper('hello')` → `'HELLO'` |
| **CHAR_LENGTH(str)** | 문자열의 문자 수 반환 | `char_length('가나다')` → `3` |
| **CONCAT(str1, str2, ...)** | 문자열을 이어붙임 | `concat('Hello', ' ', 'World')` → `'Hello World'` |
| **SUBSTRING(str, pos, len)** | 문자열 일부 추출 (1부터 카운트) | `substring('abcdef', 2, 3)` → `'bcd'` |
| **LEFT(str, n) / RIGHT(str, n)** | 왼쪽/오른쪽에서 n글자 추출 | `left('abcdef', 3)` → `'abc'` |
| **TRIM(str)** | 양쪽 공백 제거 | `trim(' hello ')` → `'hello'` |
| **REPLACE(str, from, to)** | 문자열 일부 변경 | `replace('banana', 'na', 'ny')` → `'bannya'` |
| **INSTR(str, substr)** | 특정 문자열 위치 반환 | `Instr('apple', 'p')` → `2` |
| **LPAD / RPAD** | 빈자리를 특정 문자로 채움 | `LPAD('world', 10, '*')` → `'*****world'` |
| **FORMAT(number, d)** | 천 단위 콤마 및 소수점 지정 | `format(12345, 2)` → `'12,345.00'` |

### 주요 숫자 함수
| 함수명 | 기능 | 예시 및 결과 |
| :--- | :--- | :--- |
| **ABS(x)** | 절댓값 반환 | `abs(-5)` → `5` |
| **POWER(x, y)** | x의 y제곱 계산 | `power(2, 3)` → `8` |
| **ROUND(x, d)** | 소수점 d자리 반올림 | `round(3.1415, 2)` → `3.14` |
| **CEIL(x) / FLOOR(x)** | 올림 / 내림 값 반환 | `ceil(3.2)` → `4`, `floor(3.8)` → `3` |
| **TRUNCATE(x, d)** | 소수점 d자리 자름 (버림) | `truncate(3.1415, 2)` → `3.14` |
| **MOD(x, y)** | 나머지 연산 | `mod(10, 3)` → `1` |
| **SIGN(x)** | 부호 판단 (양수 1, 0, 음수 -1) | `sign(10)` → `1` |
| **RAND()** | 0 이상 1 미만 난수 반환 | `rand()` → 예: `0.5728` |

## 3. 실전 활용 예제 10선

### 예제 1: 이메일 도메인 추출 및 대문자 변환 (`SUBSTRING`, `INSTR`, `UPPER`)
사용자 테이블(`users`)에서 이메일 주소 중 도메인 부분(`@` 뒷부분)만 추출하여 모두 대문자로 출력합니다.
```sql
SELECT email, 
       UPPER(SUBSTRING(email, INSTR(email, '@') + 1)) AS email_domain
FROM users;

```

### 예제 2: 회원 이름과 성을 조합한 풀네임 생성 (`CONCAT`)

이름(`first_name`)과 성(`last_name`) 컬럼을 결합하여 하나의 완성된 성명 컬럼으로 보여줍니다.

```sql
SELECT CONCAT(last_name, ' ', first_name) AS full_name
FROM users;

```

### 예제 3: 전화번호 뒷 4자리 마스킹 처리 (`REPLACE`, `RIGHT`, `CONCAT`)

고객의 보안을 위해 전화번호의 마지막 4자리를 `****`로 숨겨서 출력합니다.

```sql
SELECT phone, 
       CONCAT(SUBSTRING(phone, 1, CHAR_LENGTH(phone) - 4), '****') AS masked_phone
FROM users;

```

### 예제 4: 상품 검색어 입력 시 공백 제거 및 정규화 (`TRIM`, `LOWER`)

사용자가 검색창에 입력한 검색어 앞뒤의 불필요한 공백을 제거하고 소문자로 변환하여 DB 데이터와 정확히 매칭시킵니다.

```sql
SELECT * 
FROM products 
WHERE LOWER(TRIM(product_name)) = LOWER(TRIM('  iPhone 15  '));

```

### 예제 5: 상품명에 포함된 특정 단어 치환하기 (`REPLACE`)

상품명에 포함된 구버전 명칭을 신버전 명칭으로 일괄 변경하여 조회합니다.

```sql
SELECT product_id, 
       REPLACE(product_name, '2023', '2024') AS updated_product_name
FROM products;

```

### 예제 6: 상품 가격에 부가세(10%) 포함 및 소수점 반올림 (`ROUND`)

주문 금액 계산 시, 10%의 세금을 가산한 뒤 깔끔하게 소수점 첫째 자리에서 반올림합니다.

```sql
SELECT product_name, 
       price, 
       ROUND(price * 1.1, 0) AS price_with_vat
FROM products;

```

### 예제 7: 게시판 페이징 처리를 위한 총 페이지 수 계산 (`CEIL`)

전체 게시글 수(`total_posts`)를 바탕으로 한 페이지당 보여줄 게시글 수(10개) 기준의 총 페이지 수를 계산합니다.

```sql
SELECT CEIL(COUNT(*) / 10.0) AS total_pages
FROM posts;

```

### 예제 8: 재고 관리 상자(Box) 패킹 후 잔여 수량 파악 (`MOD`)

전체 재고 수량을 12개들이 한 박스 단위로 나눌 때, 박스에 담고 남은 낱개 수량을 확인합니다.

```sql
SELECT product_name, 
       stock_quantity, 
       MOD(stock_quantity, 12) AS leftover_items
FROM products;

```

### 예제 9: 주문 금액 포맷팅 및 소수점 자리 자르기 (`FORMAT`, `TRUNCATE`)

주문 총액에 천 단위 콤마를 추가하고, 성능 분석 등을 위해 소수점 아래 자릿수를 깔끔하게 잘라냅니다.

```sql
SELECT order_id, 
       FORMAT(total_amount, 0) AS formatted_amount,
       TRUNCATE(total_amount, 2) AS exact_amount
FROM orders;

```

### 예제 10: 매출 증감에 따른 부호 판별하기 (`SIGN`)

전월 대비 이번 달 매출 변화량의 증감 추세를 양수(1), 유지(0), 음수(-1) 기호로 명확하게 분류합니다.

```sql
SELECT store_id, 
       (current_month_sales - previous_month_sales) AS sales_diff,
       SIGN(current_month_sales - previous_month_sales) AS sales_trend_sign
FROM monthly_sales;

```

## 4. 마무리 요약

단일 행 함수는 데이터베이스에서 조회하는 각 행마다 독립적으로 연산을 수행하여 유연한 데이터 정제와 표현을 가능하게 해줍니다. 문자열 가공 함수와 숫자 계산 함수들을 조합하면 백엔드 로직 코드를 거치지 않고도 SQL 레벨에서 깔끔한 데이터를 가공할 수 있습니다.
