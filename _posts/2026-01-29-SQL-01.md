이번 포스팅에서는 SQL에서 데이터를 조회할 때 조건을 지정하는 **WHERE절**과 다양한 **비교/논리/SQL 연산자**, 그리고 여러 쿼리 결과를 하나로 합치거나 비교하는 **집합 연산자(Set Operators)**에 대해 정리해 보겠습니다.

---

## 1. WHERE절: SELECT문에 검색 조건 추가하기

데이터베이스에서 원하는 행(row)만 골라내고 싶을 때 사용하는 것이 바로 `WHERE`절입니다.

### 기본 문법
```sql
SELECT * | 컬럼이름 [[AS] 컬럼별칭]
FROM 테이블이름
[ WHERE 검색조건 ]
[ ORDER BY 정렬기준 ]
[ LIMIT 시작위치, 개수 ];

```

* **특징**: 특정 컬럼에 대해 지정된 검색 조건을 만족하는 행만 조회합니다.
* **사용 가능한 연산자**: 비교 연산자, 논리 연산자, SQL 연산자 등을 조합하여 사용합니다.

### 연산자 종류

* **비교 연산자**: `=`, `!=` (또는 `<>`), `<`, `<=`, `>`, `>=`
* **논리 연산자**:
* `AND` (여러 조건을 모두 만족)
* `OR` (하나 이상의 조건 만족)
* `NOT` (조건 부정)



---

## 2. 주요 SQL 연산자

WHERE절에서 더 강력한 조건을 걸기 위해 사용하는 대표적인 SQL 연산자들입니다.

### ① BETWEEN A AND B | NOT BETWEEN A AND B

* **용도**: 특정 범위 사이의 값을 조회할 때 사용합니다. 시작값과 종료값을 모두 포함하는 '이상', '이하'의 개념입니다.
* **문법**:
```sql
WHERE 컬럼명 [NOT] BETWEEN 값1 AND 값2

```


* **특징**:
* 숫자, 문자, 날짜 등 순서 비교가 가능한 타입에 사용합니다.
* `WHERE 컬럼명 >= 값1 AND 컬럼명 <= 값2` 구문과 동일합니다.
* `NOT`을 붙여 반대 범위를 조회할 수도 있습니다.



### ② IN | NOT IN

* **용도**: 목록에 포함된 여러 값 중 하나와 일치하는 데이터를 조회합니다.
* **문법**:
```sql
WHERE 컬럼명 [NOT] IN (값1, 값2, ... , 값n)

```


* **특징**:
* 여러 개의 `OR` 조건을 사용하는 것보다 가독성이 좋고 쿼리가 간결해집니다.
* *예시*: `WHERE city IN ('서울', '부산')`은 `WHERE city = '서울' OR city = '부산'`과 동일합니다.
* `NOT IN`을 사용하면 괄호 안의 값과 일치하지 않는 데이터를 필터링할 수 있습니다.



### ③ LIKE | NOT LIKE

* **용도**: 문자열 데이터에서 특정 패턴과 일치하는 값을 조회할 때 사용합니다.
* **문법**:
```sql
WHERE 컬럼명 [NOT] LIKE '패턴'

```


* **와일드카드(Wildcard) 문자 활용**:
* `%` (퍼센트): 0개 이상의 임의의 문자열
* `'김%'`: '김'으로 시작하는 모든 문자열
* `'%김'`: '김'으로 끝나는 모든 문자열
* `'%김%'`: '김'을 포함하는 모든 문자열





### ④ IS NULL | IS NOT NULL

* **용도**: 데이터의 존재 여부(NULL 여부)를 확인합니다.
* **문법**:
```sql
WHERE 컬럼명 IS [NOT] NULL

```


* **특징**:
* `NULL`은 숫자 `0`이나 빈 공백(`''`)과 다른 '존재하지 않는 값'을 의미합니다.
* 주의할 점은 `컬럼명 = NULL` 형태로 비교할 수 없으며, **반드시 `IS` 키워드를 사용**해야 합니다.
* `IS NULL`: 값이 없는(NULL) 데이터 조회
* `IS NOT NULL`: 값이 입력되어 있는(NULL이 아닌) 데이터 조회

## 3. 집합 연산자 (Set Operators)

두 개 이상의 `SELECT` 문 결과 집합을 수학의 집합 개념(합집합, 교집합, 차집합)처럼 결합하거나 비교할 때 사용합니다. 데이터 분석 시 여러 테이블의 연관 데이터를 다룰 때 매우 유용합니다.

### ⚠️ 집합 연산자 사용 전제 조건

1. 두 `SELECT` 문에서 조회하는 **컬럼의 개수가 같아야 합니다.**
2. 두 `SELECT` 문에서 조회하는 **각 컬럼의 데이터 타입이 서로 호환**되어야 합니다. (예: 숫자 타입은 숫자끼리, 문자 타입은 문자끼리)

| 구분 | 종류 | 설명 |
| --- | --- | --- |
| **합집합** | `UNION` / `UNION ALL` | 두 결과 집합을 결합 |
| **교집합** | `INTERSECT` | 공통된 결과 집합 추출 |
| **차집합** | `MINUS` (또는 `EXCEPT`) | 첫 번째 결과에서 두 번째 결과를 제외 |

### 세부 내용: UNION / UNION ALL (합집합)

두 개의 `SELECT` 문 결과를 하나로 결합합니다.

* **`UNION`**: 두 결과 집합을 합치면서 **중복된 행은 제거**합니다. (기본 동작)
* **`UNION ALL`**: 중복을 제거하지 않고 두 결과 집합을 **그대로 모두 결합**합니다. 중복 체크를 하지 않기 때문에 `UNION`보다 **성능이 더 빠릅니다.**

---

> **💡 요약 Tip**
> * 조건 검색의 기본은 `WHERE`이며, 범위는 `BETWEEN`, 목록은 `IN`, 패턴은 `LIKE`, NULL은 `IS NULL`을 기억합시다!
> * 여러 쿼리의 결과를 합칠 때는 컬럼 개수와 타입 호환 여부를 반드시 확인하고, 중복 제거 여부에 따라 `UNION`과 `UNION ALL`을 선택해 사용하세요.
