머신러닝과 딥러닝 모델은 문자나 범주형 데이터를 직접 이해하지 못하고 오직 숫자(Number)만 처리할 수 있습니다. 따라서 범주형 데이터를 숫자로 변환하는 전처리 과정이 필수적이며, 그 대표적인 방법이 바로 **원핫 인코딩**과 **임베딩**입니다.

---

## 1. 원핫 인코딩 (One-Hot Encoding)의 구체적 과정과 특징

범주형 데이터를 머신러닝 알고리즘이 처리할 수 있도록 각 범주를 독립된 이진(Binary, 0 또는 1) 형태의 벡터로 변환하는 가장 기초적인 기법입니다.

### 📌 구체적인 변환 과정

1. **고유 범주(Category) 식별**
* 분석하고자 하는 컬럼에 존재하는 전체 고유값(Unique Values)의 목록을 추출합니다. (예: `['사과', '바나나', '포도']`라면 고유 카테고리는 총 3개)


2. **차원(열) 생성**
* 추출된 고유 카테고리의 개수만큼 새로운 이진 컬럼(Feature)을 생성합니다.


3. **값 매핑 (0 또는 1 대입)**
* 각 데이터 행이 속한 카테고리에 해당하는 컬럼에는 `1`을 부여하고, 나머지 모든 컬럼에는 `0`을 부여합니다.



### 💡 구체적 예시

`['사과', '바나나', '사과', '포도']`라는 데이터가 있을 때, 고유값은 `['사과', '바나나', '포도']`이므로 3개의 차원으로 변환됩니다.

* 사과 $\rightarrow$ `[1, 0, 0]`
* 바나나 $\rightarrow$ `[0, 1, 0]`
* 포도 $\rightarrow$ `[0, 0, 1]`
* 사과 $\rightarrow$ `[1, 0, 0]`

### 👍 원핫 인코딩의 장점

* **구현의 단순성:** 직관적이고 구현하기가 매우 쉽습니다. 사이킷런(`scikit-learn`)의 `OneHotEncoder`나 판다스(`pandas`)의 `get_dummies`로 단 한 줄로 처리할 수 있습니다.
* **순서 정보의 왜곡 방지:** 예를 들어 `['빨강', '파랑', '초록']`을 `[1, 2, 3]`으로 숫자로만 바꾸면 모델이 "빨강(1) < 파랑(2)" 같은 잘못된 크기 비교나 순서 관계를 학습할 수 있습니다. 원핫 인코딩은 모든 범주가 독립된 차원을 가지므로 이러한 **서열 왜곡(Ordinal Bias)이 발생하지 않습니다.**

### ⚠️ 원핫 인코딩의 치명적인 한계점

* **차원의 저주 (Curse of Dimensionality):** 만약 카테고리의 종류가 수만 개(예: 자연어 처리의 단어장, 사용자 ID, 상품 코드 등)에 달한다면, 컬럼 수가 수만 개로 늘어나며 메모리 낭비와 연산량 폭증을 유발합니다.
* **희소성 (Sparsity):** 대부분의 값이 `0`으로 채워지고 단 하나의 값만 `1`이 되기 때문에 메모리 효율이 극도로 떨어집니다.
* **의미적 관계(Semantic Gap) 단절:** `사과`와 `바나나`는 모두 '과일'이라는 공통점이 있지만, 원핫 인코딩 벡터 상에서는 직교(Orthogonal)하는 독립된 축으로 표현되므로 둘 사이의 유사성이나 관계를 전혀 담아내지 못합니다.

## 2. 임베딩 (Embedding)이란?

원핫 인코딩의 고질적인 한계(차원의 저주와 의미 단절)를 극복하기 위해 고안된 기법으로, 범주형 데이터를 의미가 압축된 연속형 저차원 밀집 벡터(Dense Vector)로 표현하는 방식입니다.

### 🌟 임베딩의 핵심 특징

* **의미 기반 공간 배치 (Semantic Space)**
* 단어나 범주 간의 **의미적, 문맥적 유사성**을 다차원 공간 상의 거리(좌표)로 나타냅니다.
* 예를 들어 임베딩 공간에서 "강아지"와 "고양이"는 의미가 비슷하므로 벡터 공간 상에서 서로 매우 가까운 위치에 좌표가 찍힙니다. 반면 "강아지"와 "자동차"는 멀리 떨어져 배치됩니다.


* **고정된 저차원 크기 (Dense Vector)**
* 수만 개의 카테고리를 원핫 인코딩하면 5만 차원이 되지만, 임베딩은 보통 128차원, 256차원, 768차원 등 **사용자가 지정한 고정된 크기의 실수형 벡터**로 압축하여 표현합니다. (모든 값이 0이 아니므로 밀집 벡터라 부릅니다.)


* **학습을 통한 생성 (Learned Representation)**
* 사람이 수동으로 0과 1을 채우는 것이 아닙니다. 딥러닝 모델(예: 신경망의 Embedding Layer, Word2Vec, BERT 등 트랜스포머 모델)이 대규모 데이터를 학습하는 과정에서 역전파(Backpropagation)를 통해 **스스로 최적의 벡터 공간 좌표를 찾아내고 업데이트**합니다.

## 3. 원핫 인코딩과 임베딩의 종합 비교

| 비교 항목 | 원핫 인코딩 (One-Hot Encoding) | 임베딩 (Embedding) |
| --- | --- | --- |
| **벡터 형태** | 희소 벡터 (Sparse Vector, 대부분 0, 하나만 1) | 밀집 벡터 (Dense Vector, 연속된 실수값) |
| **차원의 크기** | 범주의 개수만큼 무한정 증가 ($N$차원) | 사용자가 지정한 고정 크기 (보통 저차원, 예: 128~768차원) |
| **의미 유사성 반영** | ❌ 불가 (모든 범주가 서로 독립적이고 직교함) | ⭕ 가능 (의미가 비슷한 범주는 가까운 공간에 배치) |
| **대규모 데이터 처리** | ❌ 차원의 저주로 인해 처리 불가능 (단어장 수만 개 등) | ⭕ 가능 (고정된 저차원으로 압축하여 효율적) |
| **주요 사용처** | 범주 수가 적고 순서가 없는 명목형 변수 전처리 | 자연어 처리(NLP), 대규모 추천 시스템, 딥러닝 모델의 입력층 |
