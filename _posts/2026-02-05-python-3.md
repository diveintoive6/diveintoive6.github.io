## 1. 객체지향의 4가지 핵심 개념 비유 🧬

객체지향의 기본 구조는 생물학적 구조와 매우 닮아 있습니다.

* **클래스(Class) = 설계도 = 사람의 DNA**
  * 객체를 만들기 위한 틀이자 설계도입니다. 실제로 존재하는 실체는 아니며, 속성과 기능의 정의만 들어 있습니다.
* **객체(Object / Instance) = 실제 사람**
  * 클래스라는 설계도를 바탕으로 메모리 위에 실제로 구현된 실체입니다.
* **속성(멤버 변수) = 객체의 상태(State)**
  * 객체가 가지고 있는 고유한 데이터나 성질을 의미합니다. (예: 이름, 나이, 잔액 등)
* **기능(메서드) = 객체의 행동(Behavior)**
  * 객체가 수행할 수 있는 동작이자, 객체에 소속된 함수를 의미합니다. (예: 걷기, 입금하기 등)

---

## 2. 멤버 변수(속성)와 메서드(기능)의 상세 개념

### 🔹 멤버 변수 (Member Variable / Attribute)
* **정의:** 객체가 상태로 가지고 있는 변수입니다. 객체가 "지금 어떤 상태인가"를 표현합니다.
* **종류:**
  1. **인스턴스 변수:** 객체(인스턴스)마다 따로 존재하며, 보통 `__init__` 메서드 안에서 `self.변수명` 형태로 정의합니다. (객체마다 값이 다름)
  2. **클래스 변수:** 클래스 블록 안에서 직접 정의하며, **모든 객체가 공유**하는 변수입니다.

### 🔹 메서드 (Method)
* **정의:** 객체가 수행할 수 있는 **동작(행동)**을 표현하는, 객체에 소속된 함수입니다.
* **종류:**
  1. **인스턴스 메서드:** 가장 일반적인 형태이며, 첫 번째 매개변수로 객체 자신을 뜻하는 `self`를 받습니다.
  2. **클래스 메서드:** `@classmethod`를 사용하며, 객체가 아닌 클래스 자체를 대상으로 동작합니다 (`cls` 사용).
  3. **정적 메서드:** `@staticmethod`를 사용하며, 객체나 클래스의 상태와 무관하게 독립적으로 동작하는 유틸리티 함수입니다.

## 3. 코드로 보는 클래스 구조 예시

실제 코드를 통해 멤버 변수와 메서드가 어떻게 동작하는지 살펴보겠습니다.

```python
class Account:
    # 1️⃣ 클래스 변수 (모든 객체가 공유)
    bank_name = "Python Bank" 

    def __init__(self, owner, balance):
        # 2️⃣ 인스턴스 변수 (객체마다 독립적인 데이터 보유)
        self.owner = owner
        self.balance = balance 

    # 3️⃣ 인스턴스 메서드 (객체의 상태를 바꾸는 행동)
    def deposit(self, amount):
        self.balance += amount
        print(f"{self.owner님} {amount}원 입금 → 잔액: {self.balance}")

    def withdraw(self, amount):
        if amount > self.balance:
            print("잔액 부족!")
            return
        self.balance -= amount
        print(f"{self.owner님} {amount}원 출금 → 잔액: {self.balance}")

    # 4️⃣ 클래스 메서드
    @classmethod
    def change_bank_name(cls, name):
        cls.bank_name = name

    # 5️⃣ 정적 메서드
    @staticmethod
    def is_valid_amount(amount):
        return amount > 0

```

### 객체 생성 및 활용

```python
# 객체(인스턴스) 생성
acc1 = Account("철수", 1000)
acc2 = Account("영희", 2000)

# 인스턴스 메서드 호출 (각각의 상태가 독립적으로 변경됨)
acc1.deposit(500)  # 출력: 철수님 500원 입금 → 잔액: 1500
acc2.deposit(300)  # 출력: 영희님 300원 입금 → 잔액: 2300

```

## 4. 파이썬 접근 제어의 특징 (정보 은닉)

자바나 C++ 같은 언어에는 `private`, `protected` 같은 엄격한 접근 제어 키워드가 존재하지만, 파이썬은 강제로 막지 않고 "개발자간의 약속(관례)"으로 처리합니다.

* `self.public` : 누구나 접근 가능
* `self._protected` : 내부적으로만 쓰기로 한 변수 (외부 접근은 가능하지만 권장하지 않음)
* `self.__private` : 외부에서 직접 접근하기 어렵도록 이름 맹글링(Name Mangling) 처리됨

## 💡 핵심 요약 (면접·시험용)

| 개념 | 설명 |
| --- | --- |
| **클래스 (Class)** | 객체를 만들어내기 위한 설계도 (DNA) |
| **객체 (Object)** | 설계도를 기반으로 메모리에 생성된 실체 (사람) |
| **멤버 변수 (속성)** | 객체의 **상태(데이터)**를 나타내는 변수 |
| **메서드 (기능)** | 객체가 수행할 수 있는 **동작(행동)**을 정의한 함수 |
| **`self`** | 메서드가 호출된 **현재 객체(인스턴스) 자신**을 가리키는 참조 |
