## 1. 슬라이싱을 통한 리스트의 확장과 축소

파이썬에서는 슬라이싱 범위를 지정하고 값을 대입하는 방식으로 리스트의 크기를 유연하게 조절할 수 있습니다.

* **리스트의 확장**: 슬라이싱으로 지정된 구간의 길이보다 더 긴 리스트를 대입하는 경우
* **리스트의 축소**: 슬라이싱으로 지정된 구간의 길이보다 짧은 길이의 리스트를 대입하는 경우

```python
mylist = [10, 20, 30, 40, 50]

# 1. 지정된 범위보다 크기가 큰 리스트 대입 -> 리스트의 확장
mylist[1:4] = [100, 200, 300, 400]
print(mylist)
# 출력: [10, 100, 200, 300, 400, 50]

# 2. 지정된 범위보다 크기가 작은 리스트 대입 -> 리스트의 축소
mylist[1:4] = [100, 200]
print(mylist)
# 출력: [10, 100, 200, 50]
```

## 2. 변수 복사: 깊은 복사와 얕은 복사

### (1) 일반 변수의 깊은 복사 (값의 복사)
정수, 실수, 문자열, 논리값 같은 기본 데이터 타입은 변수끼리 대입할 때 **값을 복사**합니다. 따라서 복사본을 변경해도 원본에는 영향을 주지 않습니다.

```python
a = 100
b = a
print(a, b)  # 100 100

b = 200
print(a, b)  # 100 200 (원본은 유지됨)
```

### (2) 연속성 자료형의 얕은 복사 (참조)
리스트, 딕셔너리 같은 연속성 자료형은 대입 연산자(`=`)를 사용할 때 복사가 아닌 **참조(Reference)**가 이루어집니다. 즉, 복사본을 변경하면 원본도 함께 변경됩니다.

```python
foo = [1, 2, 3]
bar = foo  # 참조 전달

bar[1] = 20
print(foo)  # [1, 20, 3] -> 원본도 함께 변경됨!
print(bar)  # [1, 20, 3]
```

---

## 3. 연속성 자료형의 깊은 복사 방법 3가지

참조가 아닌 실질적인 데이터 복사(깊은 복사)를 수행하는 방법은 다음과 같습니다.

### ① 고전적인 개별 원소 복사
같은 길이의 새로운 리스트를 만들고 원소를 하나씩 직접 대입하는 방식입니다.

```python
bar = [1, 2, 3]
cp1 = [0, 0, 0]
cp1[0] = bar[0]
cp1[1] = bar[1]
cp1[2] = bar[2]

cp1[2] = 1000
print(bar)  # [1, 2, 3]
print(cp1)  # [1, 2, 1000]
```

### ② 슬라이싱을 활용한 복사
전체 범위를 슬라이싱(`[:]`)하여 새로운 객체로 복사합니다.

```python
hello = [100, 200, 300]
cp2 = hello[:]

cp2[1] = 12345
print(hello)  # [100, 200, 300]
print(cp2)  # [100, 12345, 300]
```

### ③ `copy()` 메서드 활용 (가장 추천)
리스트 객체의 `copy()` 메서드를 사용하는 방식이며, 리스트 복사의 **가장 표준적이고 효율적인 방법**입니다.

```python
world = ["hello", "python", "world"]
cp3 = world.copy()

cp3[0] = "nice"
print(world)  # ['hello', 'python', 'world']
print(cp3)    # ['nice', 'python', 'world']
```

## 4. 튜플(Tuple)의 이해

튜플은 리스트와 동일한 특성을 갖는 연속성 자료형이지만, 소괄호(`()`)를 사용하며 **한번 생성한 후 원소의 값을 수정(변경)할 수 없다**는 결정적인 차이가 있습니다. 

```python
# 5명의 학생에 대한 성적 나열
grade = (98, 82, 73, 64, 100)
print(grade)  # (98, 82, 73, 64, 100)

# 원소의 1:1 변수 할당은 리스트와 동일하게 가능
a, b = (1, 2)
```
> **참고**: 원소 변경이 불가능하다는 제약 때문에 리스트에 비해 활용도가 상대적으로 낮습니다.

## 5. 리스트 관련 연산자와 내장 함수

### ① 포함 여부 확인 (`in`, `not in`)
특정 값이 리스트에 포함되어 있는지 확인할 때 사용합니다. 결과는 불리언(`True`/`False`)로 반환됩니다.

```python
mylist = [1, 3, 5]
target = 5

find = target in mylist
print(find)  # True
```

### ② 길이 및 원소 제거 (`len()`, `del`)
* `len()`: 리스트나 튜플의 원소 개수(길이)를 반환합니다.
* `del`: 지정된 인덱스의 원소를 제거합니다.

```python
mylist = [10, 20, 30, 40, 50]
print(len(mylist))  # 5
```

## 6. 리스트 탐색 방법 (반복문)

### ① 인덱스를 활용한 반복문과 `enumerate()`
리스트를 순회할 때 인덱스와 원소 값을 동시에 취득하려면 `enumerate()` 함수를 사용하는 것이 편리합니다.

```python
# 기본 인덱스 탐색 패턴
for i in range(0, len(mylist)):
    print(mylist[i])

# 리스트 자체를 탐색하는 패턴
for i in mylist:
    print(i)

# 인덱스와 원소를 동시에 탐색 (enumerate)
for i, v in enumerate(mylist):
    print(f"인덱스: {i}, 값: {v}")
```

> **💡 2차원 리스트 탐색 주의사항**
> 2차원 리스트는 내부의 행(row)마다 길이가 다를 수 있으므로 2중 반복문을 사용할 때 주의해야 합니다.
> ```python
> for row in mydata:
>     for col in row:
>         print(col)
> ```

## 7. 정렬 및 집계 함수

### ① 정렬 (`sorted()`)
파라미터로 전달된 리스트를 정렬한 **새로운 복사본**을 리턴합니다. 원본 리스트는 유지됩니다.

```python
mylist = [4, 2, 5, 3, 1]

asc = sorted(mylist)               # 순차 정렬 (오름차순)
desc = sorted(mylist, reverse=True)  # 역순 정렬 (내림차순)

print(asc)   # [1, 2, 3, 4, 5]
print(desc)  # [5, 4, 3, 2, 1]
print(mylist) # [4, 2, 5, 3, 1] (원본은 변경되지 않음)
```

### ② 집계 함수 (`max()`, `min()`, `sum()`)
* `max()`: 최댓값 반환
* `min()`: 최솟값 반환
* `sum()`: 합계 반환

> ⚠️ **주의**: 문자열이 포함된 리스트에서는 위 함수들의 연산이 불가능하며, 평균을 구할 때는 `sum()` 결과와 `len()`을 활용해 직접 계산해야 합니다.
```python
total = sum(mylist)
average = total / len(mylist)
