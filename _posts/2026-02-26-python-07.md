파이썬의 **객체지향 프로그래밍(Object-Oriented Programming, OOP)** 개념인 클래스(Class), 객체(Object), 생성자(`__init__`), 그리고 데이터 보호를 위한 **캡슐화와 프로퍼티(`@property`)**의 상세한 활용법에 대해 알아봅니다.

---

## 1. 객체지향 프로그래밍(OOP)의 이해

### ① 객체(Object)란?
* 필요에 따라 다른 변수와 함수를 내장하고 있는 특수한 변수입니다.
* **현실 세계의 반영:** 객체의 의미는 "현실 세계에 존재하는 것"을 뜻하며, 이를 프로그래밍 언어로 표현한 것을 **객체지향 언어**라고 합니다.
* 특정 기능을 **명사적 특성**과 **동사적 특성**으로 구분하여 정의합니다.
  * **명사적 특성 (= 멤버 변수 / 속성):** 아이디, 이메일 주소 등 데이터
  * **동사적 특성 (= 메서드 / 함수):** 가입(`join()`), 로그인(`login()`) 등 기능
> **핵심 요약:** 객체 = 데이터(변수) + 기능(함수)

## 2. 클래스(Class)와 객체의 생성

### ① 클래스 (Class)
* 객체를 생성하기 위한 **설계도** 역할을 하는 프로그램 소스입니다.
* 공장의 설계도로 여러 개의 제품(제품A, 제품B...)을 찍어낼 수 있는 것처럼, 하나의 클래스로 동일한 구조를 갖는 **독립적인 객체**를 여러 개 생성할 수 있습니다.

### ② 클래스 작성 방법
`class` 예약어를 사용하여 정의하며, 멤버 변수와 메서드를 포함할 수 있습니다.
```python
class 클래스이름:
    멤버변수 = 값  # 직접 초기화 또는 None으로 지정 후 간접 대입

    def 메서드이름(self, 파라미터...):
        # 실행할 코드
        return 값

```

### ③ 클래스를 통한 객체 생성

```python
변수이름 = 클래스이름()

```

* 이렇게 생성된 변수를 **객체**라고 부르며, 클래스 내의 모든 멤버 변수와 메서드를 부여받습니다.
* **접근 방식:** 점(`.`)을 통해 접근합니다.
* 멤버 변수 출력: `print(객체.멤버변수)`
* 변수에 데이터 복사: `변수 = 객체.멤버변수`
* 메서드 호출: `객체.메서드()`

## 3. 메서드와 `self` 키워드의 이해

### ① `self`의 의미

* 파이썬에서는 클래스에 포함되는 모든 메서드의 **첫 번째 파라미터로 `self`를 반드시 정의**해야 합니다.
* `self`는 **객체 자기 자신**을 가리키는 키워드입니다.
* 객체를 통해 메서드가 호출될 때는 `self`에 값이 자동으로 전달되므로, 호출 시에는 `self`에 해당하는 파라미터에 값을 넘기지 않습니다.

```python
class Calc:
    def plus(self, x, y):
        return x + y

    def minus(self, x, y):
        return x - y

    def all_calc(self, x, y):
        # 클래스 안의 다른 메서드를 호출할 때는 반드시 self를 통해야 합니다.
        z = self.plus(x, y) * self.minus(x, y)
        return z

```

### ② 메서드 안에서 멤버 변수 접근하기

* 클래스에 속한 메서드에서 멤버 변수에 접근하려면 반드시 `self`를 통해서만 가능합니다.
* 멤버 변수는 클래스 안의 모든 메서드가 공유할 수 있는 **전역 변수**의 역할을 합니다.

```python
class User:
    user_id = None  # 멤버 변수

    def setUserId(self, user_id):
        self.user_id = user_id  # self를 통한 멤버 변수 접근

    def getUserId(self):
        return self.user_id

u = User()
u.setUserId("helloworld")
print(u.getUserId())  # 출력: helloworld

```

## 4. 생성자 (`__init__`)

### ① 생성자란?

* 객체가 생성될 때 **자동으로 실행되는 특수한 형태의 메서드**입니다.
* 값을 리턴하지 않으며, 이름은 **`__init__`** (앞뒤로 언더바 두 개)으로 약속되어 있습니다.
* 객체가 생성될 때 멤버 변수를 초기화하는 용도로 사용됩니다.

```python
class Foo:
    name = None
    age = None

    def __init__(self, name, age):
        # 생성자 파라미터의 값을 멤버 변수에 복사하여 초기화
        self.name = name
        self.age = age

# 객체 생성과 동시에 파라미터 전달
obj = Foo("파이썬", 20)

```

> **생성자의 의의:** 객체 생성과 멤버 변수 초기화 과정을 축약하여 효율적으로 처리할 수 있습니다.

## 5. 캡슐화(Encapsulation)와 정보 은닉

### ① 캡슐화의 필요성

* 객체를 사용하는 측의 실수로 인해 잘못된 데이터가 저장되는 것을 방지하기 위해, 클래스의 구체적인 정보를 숨기는 기법입니다.
* *예시 문제점:* 점수(`kor`) 멤버 변수가 객체에 그대로 노출될 경우, 사용자가 실수로 `stud.kor = -50`과 같이 잘못된 값을 직접 대입해도 프로그램은 이를 막지 못하고 그대로 저장하게 됩니다.

### ② 접근 한정자 (`__` private)

파이썬에서는 멤버 변수나 메서드 이름 앞에 `__` (언더바 두 개)를 붙이면 외부에서 직접 접근할 수 없는 **Private** 상태가 됩니다.

* `없음 (Public)`: 객체를 통한 직접 접근 가능
* `__변수명, __메서드명 (Private)`: 객체를 통한 직접 접근이 불가능하도록 은닉됨

## 6. 프로퍼티(`@property`)를 활용한 정보 은닉과 안전한 제어 (심화)

### ① 프로퍼티란 무엇인가?

멤버 변수가 은닉(`__`)되면 데이터에 직접 접근하는 길이 사라집니다. 이를 해결하기 위해 고전적으로는 `getter`/`setter` 메서드(`getPoint()`, `setPoint()`)를 만들었으나, 코드가 장황해지고 객체를 사용할 때 변수처럼 직관적으로 다루기 불편하다는 단점이 있었습니다.

프로퍼티(Property)는 은닉된 멤버 변수에 간접적으로 안전하게 접근하면서도, **일반 변수처럼 마침표(`.`)를 이용해 손쉽게 읽고 쓸 수 있게 해주는 파이썬의 강력한 데코레이터(`@`) 기능**입니다.

### ② 프로퍼티의 구성요소 (Getter와 Setter)

1. **Getter (`@property`)**: 은닉된 멤버 변수의 값을 **읽어(리턴)** 오기 위한 메서드입니다. *(※ 주의: Setter보다 반드시 먼저 정의되어야 합니다.)*
2. **Setter (`@property_name.setter`)**: 파라미터로 전달된 값을 검사한 뒤 은닉된 멤버 변수에 대입(저장)하기 위한 메서드입니다. 값을 대입하기 전 `if`문 등을 통해 데이터의 적합성을 완벽하게 검증할 수 있습니다.

### ③ 완벽한 프로퍼티 구현 및 작동 예시

```python
class Foo:
    __member_var = None  # 은닉된 멤버 변수

    @property
    def my_prop(self):
        """Getter 메서드: 멤버 변수를 리턴한다. (반드시 setter보다 먼저 정의되어야 함)"""
        return self.__member_var

    @my_prop.setter
    def my_prop(self, value):
        """Setter 메서드: 값을 대입하기 전, 조건문으로 적합한지 검사할 수 있다."""
        if value < 0:
            value = 0  # 잘못된 값 방지 예외 처리
        self.__member_var = value

    def __init__(self, value):
        # 생성자가 직접 값을 초기화하지 않고 setter를 호출한다.
        self.my_prop = value

# 프로퍼티 사용하기
f = Foo(50)
f.my_prop = 100        # setter 메서드가 호출됨
print(f.my_prop)       # getter 메서드가 호출됨 (출력: 100)

```

유효성 검증 로직까지 추가하면 다음과 같다

```python
class Student:
    # 은닉된 멤버 변수 (외부에서 직접 접근 불가)
    __kor = None

    @property
    def kor(self):
        """
        [Getter 메서드]
        - 은닉된 __kor 변수의 값을 리턴합니다.
        - 객체.kor 형식으로 값을 읽어올 때 자동으로 실행됩니다.
        """
        return self.__kor

    @kor.setter
    def kor(self, value):
        """
        [Setter 메서드]
        - 객체.kor = 값 형식으로 값을 대입할 때 자동으로 실행됩니다.
        - 값을 대입하기 전에 유효성 검사(데이터 필터링)를 수행할 수 있습니다.
        """
        if value < 0:
            print("경고: 점수는 0 미만일 수 없습니다. 0으로 강제 지정됩니다.")
            self.__kor = 0
        elif value > 100:
            print("경고: 점수는 100을 초과할 수 없습니다. 100으로 강제 지정됩니다.")
            self.__kor = 100
        else:
            self.__kor = value

    def __init__(self, kor_score):
        # 생성자에서 멤버 변수에 직접 대입하지 않고, 
        # 반드시 안전한 Setter(프로퍼티)를 거치도록 설계합니다.
        self.kor = kor_score


# --- 프로퍼티 사용하기 ---

# 1. 객체 생성 및 초기값 전달 (Setter 호출됨)
stud = Student(90)
print(f"초기 국어 점수: {stud.kor}")  # Getter 호출됨 -> 출력: 90

# 2. 올바른 값 대입 (Setter 호출됨)
stud.kor = 85
print(f"수정된 국어 점수: {stud.kor}")  # Getter 호출됨 -> 출력: 85

# 3. 잘못된 값(음수) 대입 시도 (Setter의 예외 검증 로직 작동)
stud.kor = -50  
print(f"오류 발생 후 점수: {stud.kor}")  # 출력: 경고 메시지 출력 후 0으로 저장됨

```

### ④ 프로퍼티 사용의 핵심 요약

* 프로퍼티로 묶인 메서드들은 **마치 일반 멤버 변수처럼 (`객체.이름 = 값`, `print(객체.이름)`)** 사용할 수 있습니다.
* 값을 대입(`=`)하는 구문을 사용하면 내부적으로 **Setter**가 실행되고, 값을 불러오는(`print` 등) 구문을 사용하면 내부적으로 **Getter**가 실행됩니다.
* 이를 통해 객체의 무결성(데이터의 정확성과 안정성)을 보장하면서도 개발자가 직관적으로 코드를 작성할 수 있게 됩니다.

```
