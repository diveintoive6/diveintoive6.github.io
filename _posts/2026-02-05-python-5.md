파이썬 반복문에서 인덱스와 값을 동시에 다루고 싶을 때 가장 유용하게 쓰이는 함수가 바로 `enumerate()`입니다.

이번 글에서는 `enumerate()`가 내부적으로 무엇을 반환하는지, 그리고 변수를 **1개** 받을 때와 **2개** 받을 때(튜플 언패킹)의 차이가 코드에서 어떻게 나타나는지 명확하게 정리해 보겠습니다.

---

## 1. `enumerate()`의 기본 개념

`enumerate()`는 순회 가능한(iterable) 객체(리스트, 문자열 등)를 받아 각 요소에 **인덱스 번호**를 부여하고, 이를 `(인덱스, 값)` 형태의 튜플(Tuple)로 묶어서 반환해 주는 함수입니다.

```python
csv_list = ["제목행\n", "2020-01-01,5,0\n", "2020-01-02,3,0\n"]

for item in enumerate(csv_list):
    print(item)

```

**출력 결과:**

```text
(0, '제목행\n')
(1, '2020-01-01,5,0\n')
(2, '2020-01-02,3,0\n')

```

👉 반환되는 값 자체가 하나의 `튜플(Tuple)` 형태라는 점이 핵심입니다.

---

## 2. 변수 1개 vs 2개: 튜플 그대로 받기 vs 튜플 언패킹

`enumerate()`가 반환하는 튜플을 변수에 어떻게 담느냐에 따라 코드의 형태가 달라집니다.

### ① 변수 1개로 받을 때 (튜플 그대로 저장)

변수를 하나만 지정하면, 반환되는 튜플 전체가 그 변수에 그대로 들어갑니다. 따라서 인덱스와 값에 접근하려면 인덱싱(`[0]`, `[1]`)을 거쳐야 합니다.

```python
for item in enumerate(csv_list):
    x = item[0]  # 인덱스 번호 추출
    y = item[1]  # 실제 데이터 행 추출
    print(x, y)

```

* **특징:** 튜플의 구조를 그대로 유지하므로 직관적이지 않고 매번 `item[0]`, `item[1]`을 타이핑해야 하는 번거로움이 있습니다.

### ② 변수 2개로 받을 때 (튜플 자동 언패킹, 실무 표준)

변수를 쉼표로 구분하여 두 개(`x, y`) 지정하면, 파이썬이 알아서 튜플을 쪼개서 각각의 변수에 넣어줍니다. 이를 튜플 언패킹(Unpacking)이라고 부릅니다.

```python
for x, y in enumerate(csv_list):
    print(x, y)

```

* **특징:** 코드가 매우 간결해지며, `x`에는 인덱스, `y`에는 실제 값이 바로 매핑되어 실무에서 가장 권장되는 방식입니다.

## 3. 실전 코드 비교 (`covid19.csv` 예시 적용)

실제 데이터 처리 코드에서 두 방식이 어떻게 다르게 구현되는지 비교해 보겠습니다.

### 📌 버전 1: 변수 1개로 처리할 때

```python
try:
    with open("covid19.csv", 'r', encoding='euc-kr') as f:
        csv_list = f.readlines()

        for item in enumerate(csv_list):
            x = item[0]  # 튜플에서 인덱스 추출
            y = item[1]  # 튜플에서 데이터 행 추출

            if x == 0:
                continue

            리스트 = y.strip().split(",")
            if 리스트[1].isnumeric():
                서울_확진자수 += int(리스트[1])
except Exception as e:
    print("처리 실패", e)

```

### 📌 버전 2: 변수 2개(언패킹)로 처리할 때 (추천)

```python
try:
    with open("covid19.csv", 'r', encoding='euc-kr') as f:
        csv_list = f.readlines()

        for x, y in enumerate(csv_list):  # 튜플이 자동으로 x와 y로 쪼개짐
            if x == 0:
                continue

            리스트 = y.strip().split(",")
            if 리스트[1].isnumeric():
                서울_확진자수 += int(리스트[1])
except Exception as e:
    print("처리 실패", e)

```

## 4. 한눈에 보는 비교 요약 표

| 구분 | 변수 1개로 받기 | 변수 2개로 받기 (언패킹) |
| --- | --- | --- |
| **문법 예시** | `for item in enumerate(csv_list):` | `for x, y in enumerate(csv_list):` |
| **변수 형태** | `item` $\rightarrow$ `(인덱스, 값)` 튜플 전체 | `x` $\rightarrow$ 인덱스, `y` $\rightarrow$ 값 |
| **값 접근 방법** | `item[0]` (인덱스), `item[1]` (값) | `x`, `y` 변수를 바로 사용 가능 |
| **코드 가독성** | 다소 번거로움 (`item[0]` 반복) | 매우 깔끔하고 직관적 |
| **추천 여부** | 튜플 구조 학습/확인용 | **실무 및 일반적인 개발 표준** |
