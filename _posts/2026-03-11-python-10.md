객체지향 프로그래밍(OOP)을 공부할 때 가장 헷갈리기 쉬운 개념 중 하나가 바로 **오버라이딩(Overriding)**과 **오버로딩(Overloading)**입니다. 이름이 비슷해서 혼동하기 쉽지만, 적용되는 위치와 목적이 완전히 다릅니다.

---

## 1. 한눈에 보는 비교 (Overriding vs Overloading)

| 구분 | 오버라이딩 (Overriding) | 오버로딩 (Overloading) |
| :--- | :--- | :--- |
| **적용 관계** | **상속 관계** (부모와 자식 클래스) | **동일 클래스** 내부 |
| **핵심 개념** | 부모의 메서드를 자식이 **재정의** | 같은 이름의 메서드를 **매개변수를 달리하여 여러 개** 정의 |
| **메서드 조건** | 이름, 매개변수, 리턴 타입이 **모두 일치**해야 함 | 이름은 같지만 **매개변수의 개수나 타입이 달라야 함** |
| **목적** | 부모의 기능을 자식의 특성에 맞게 **변경** | 같은 기능의 메서드를 매개변수에 따라 **유연하게 호출** |

---

## 2. 오버라이딩 (Overriding)

* **정의:** 상속 관계에서 부모 클래스가 가지고 있는 메서드를 자식 클래스가 물려받은 뒤, **내용을 고쳐서(재정의해서)** 사용하는 것입니다.
* **특징:** 
  * 메서드 이름, 매개변수, 리턴 타입이 모두 부모 클래스와 **완벽히 동일**해야 합니다.
  * 오직 함수 내부의 실행 내용(코드)만 자식에 맞게 바뀝니다.
* **한 줄 요약:** *"부모가 물려준 기능을 내 입맛에 맞게 재정의한다."*

### 📌 오버라이딩 코드 예시

#### [Java]

```java
class Animal {
    void sound() {
        System.out.println("동물이 울음소리를 냅니다.");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("멍멍!");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal myAnimal = new Animal();
        myAnimal.sound(); // 출력: 동물이 울음소리를 냅니다.

        Dog myDog = new Dog();
        myDog.sound();    // 출력: 멍멍!
    }
}

```

#### [Python]

```python
class Animal:
    def sound(self):
        print("동물이 울음소리를 냅니다.")

class Dog(Animal):
    def sound(self):  # 부모의 sound 메서드를 오버라이딩
        print("멍멍!")

# 테스트
my_animal = Animal()
my_animal.sound()  # 출력: 동물이 울음소리를 냅니다.

my_dog = Dog()
my_dog.sound()     # 출력: 멍멍!

```

## 3. 오버로딩 (Overloading)

* **정의:** 하나의 클래스 내에서 **이름이 같은 메서드를 여러 개** 정의하는 것입니다.
* **특징:**
* 이름은 똑같지만 **매개변수(파라미터)의 개수나 타입**이 달라야 합니다.
* *참고:* 단순히 리턴 타입만 다른 것은 오버로딩이 성립되지 않습니다.
* **Python의 특징:** 파이썬은 언어 특성상 **전통적인 메서드 오버로딩을 지원하지 않습니다.** 같은 이름으로 여러 함수를 정의하면 가장 아래에 정의된 함수만 남게 됩니다. 따라서 파이썬에서는 기본값(Default Argument)이나 가변 인자(`*args`)를 활용해 오버로딩과 같은 효과를 냅니다.



### 📌 오버로딩 코드 예시

#### [Java] (전통적인 오버로딩 지원)

```java
class MathUtils {
    // 정수 2개를 더하는 메서드
    int add(int a, int b) {
        return a + b;
    }

    // 실수 2개를 더하는 메서드 (매개변수 타입이 다름)
    double add(double a, double b) {
        return a + b;
    }

    // 정수 3개를 더하는 메서드 (매개변수 개수가 다름)
    int add(int a, int b, int c) {
        return a + b + c;
    }
}

public class Main {
    public static void main(String[] args) {
        MathUtils math = new MathUtils();

        System.out.println(math.add(10, 20));          // 출력: 30
        System.out.println(math.add(5.5, 2.1));        // 출력: 7.6
        System.out.println(math.add(1, 2, 3));         // 출력: 6
    }
}

```

#### [Python] (기본값/가변인자를 통한 오버로딩 구현)

```python
class MathUtils:
    # 파이썬은 기본값 인자를 활용해 여러 형태의 호출을 유연하게 처리합니다.
    def add(self, a, b=0, c=0):
        return a + b + c

math = MathUtils()

print(math.add(10, 20))      # 출력: 30 (a=10, b=20, c=0)
print(math.add(1, 2, 3))     # 출력: 6  (a=1, b=2, c=3)

```
