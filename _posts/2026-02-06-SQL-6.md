파이썬(`pymysql`)을 통해 MySQL 데이터를 조회할 때, 단순히 테이블에서 데이터를 긁어오는 것만으로는 해결할 수 없는 복잡한 비즈니스 로직들이 존재합니다. 

그중 실무에서 데이터 가공 및 필터링 시 가장 강력하고 빈번하게 사용되는 **`CASE WHEN` 조건부 분기 처리**, **서브쿼리 및 인라인 뷰**, 그리고 **가상 테이블을 저장하고 재사용하는 뷰(View)와 CTE**의 개념을 집중적으로 파헤쳐 보겠습니다.

## 1. 조건부 분기 처리 (`CASE WHEN ~ THEN`)

파이썬의 `if-elif-else` 문처럼, SQL 쿼리 내부에서 특정 조건에 따라 동적으로 결과값을 변환하여 조회하고 싶을 때 사용합니다. 

데이터를 원본 그대로 가져와서 파이썬에서 반복문을 돌며 분기 처리를 하는 것보다, **데이터베이스 단계에서 미리 가공해서 가져오는 것이 성능과 코드 간결성 측면에서 훨씬 유리**합니다.

### 📌 기본 문법 구조
```sql
CASE 
    WHEN 조건1 THEN 결과값1
    WHEN 조건2 THEN 결과값2
    ELSE 기본결과값
END AS 별칭

```

### 🐍 Python 연동 실습 예시

학생들의 점수(`score`)에 따라 등급(A, B, C, F)을 자동으로 매겨서 파이썬으로 가져오는 코드입니다.

```python
import pymysql

mysql = pymysql.connect(
    host="127.0.0.1", port=9090, user="ive", passwd="root", 
    db="myschool", charset="utf8mb4", use_unicode=True
)
cursor = mysql.cursor()
cursor.execute("SET NAMES utf8mb4")

sql = """
    SELECT 
        name, 
        score,
        CASE 
            WHEN score >= 90 THEN 'A'
            WHEN score >= 80 THEN 'B'
            WHEN score >= 70 THEN 'C'
            ELSE 'F'
        END AS grade_rank
    FROM student;
"""

cursor.execute(sql)
results = cursor.fetchall()

print("--- 학생 성적 등급 조회 결과 ---")
for row in results:
    print(f"이름: {row[0]}, 점수: {row[1]}점, 등급: {row[2]}")

mysql.close()

```

### 📊 실행 결과 예시

```text
--- 학생 성적 등급 조회 결과 ---
이름: 김철수, 점수: 92점, 등급: A
이름: 이영희, 점수: 85점, 등급: B
이름: 박민수, 점수: 68점, 등급: F

```

## 2. 서브쿼리 (Subquery)와 인라인 뷰 (Inline View)

서브쿼리는 하나의 SQL 문장 안에 포함된 또 다른 SQL 문장을 뜻합니다. 메인 쿼리를 보조하는 역할을 하며, 위치에 따라 불리는 이름과 활용도가 달라집니다.

### ① WHERE 절 서브쿼리 (조건 필터링용)

전체 학생의 평균 점수보다 높은 점수를 받은 학생들을 뽑고 싶을 때 사용합니다.

```sql
SELECT name, score 
FROM student 
WHERE score > (SELECT AVG(score) FROM student);

```

### ② 인라인 뷰 (Inline View - FROM 절 서브쿼리)

**인라인 뷰**는 `FROM` 절에 위치하는 서브쿼리를 말합니다. 쿼리 실행 시 **마치 새로운 임시 테이블(가상 테이블)처럼 동작**하기 때문에, 데이터 전체를 조인하기 전에 미리 집계나 필터링을 거쳐 연산량을 줄일 때 유용합니다.

```sql
-- 학년별 평균 점수를 구한 가상 테이블을 활용해 80점 이상인 학년 조회
SELECT t.grade, t.avg_score
FROM (
    SELECT grade, AVG(score) AS avg_score
    FROM student
    GROUP BY grade
) AS t
WHERE t.avg_score >= 80;

```

## 3. MySQL의 가상 테이블: 뷰(View)와 CTE(Common Table Expression)

매번 복잡한 인라인 뷰나 서브쿼리를 쿼리마다 길게 작성하는 것은 비효율적입니다. MySQL에서는 가상 테이블을 **이름을 붙여 영구적으로 저장**하거나, **쿼리 안에서 임시로 이름을 붙여 깔끔하게 정리**하는 기능을 제공합니다.

### ① 뷰 (View, `CREATE VIEW`)

* **개념:** 복잡한 `SELECT` 쿼리 결과 자체를 데이터베이스 내에 **가상 테이블(Virtual Table)** 형태로 저장해 두고, 마치 실제 테이블처럼 조회할 수 있게 해주는 기능입니다. (데이터를 직접 저장하는 것이 아니라, 쿼리 자체를 저장합니다.)
* **장점:** 복잡한 조인이나 집계 쿼리를 매번 타이핑할 필요 없이, 일반 테이블처럼 `SELECT * FROM 뷰이름`으로 간단하게 호출할 수 있어 보안성과 가독성이 뛰어납니다.

```sql
-- 1. 가상 테이블(뷰) 생성하기
CREATE VIEW v_grade_stats AS
SELECT grade, AVG(score) AS avg_score, COUNT(*) AS student_cnt
FROM student
GROUP BY grade;

-- 2. 생성된 뷰를 일반 테이블처럼 조회하기 (파이썬에서도 이 뷰 이름만 호출하면 됨)
SELECT * FROM v_grade_stats WHERE avg_score >= 80;

```

### ② CTE (Common Table Expression, `WITH` 절)

* **개념:** 인라인 뷰가 너무 길어져서 가독성이 떨어질 때, 쿼리의 맨 상단에 **`WITH`** 키워드를 써서 임시 가상 테이블을 정의하고 메인 쿼리에서 호출하는 현대적인 SQL 문법입니다.
* **장점:** 뷰를 매번 데이터베이스에 영구 생성하지 않고, 해당 쿼리가 실행되는 동안에만 메모리상에 임시로 존재하므로 관리가 깔끔합니다.

```sql
-- WITH 절을 이용한 가상 테이블 정의 및 조회
WITH grade_summary AS (
    SELECT grade, AVG(score) AS avg_score, COUNT(*) AS student_cnt
    FROM student
    GROUP BY grade
)
SELECT grade, avg_score, student_cnt
FROM grade_summary
WHERE student_cnt >= 5;

```

### 🐍 Python 연동 실습 예시 (CTE 활용)

복잡한 집계 로직을 `WITH` 절(CTE)로 깔끔하게 정리하여 파이썬에서 안전하게 호출하는 코드입니다.

```python
import pymysql

mysql = pymysql.connect(
    host="127.0.0.1", port=9090, user="ive", passwd="root", 
    db="myschool", charset="utf8mb4", use_unicode=True
)
cursor = mysql.cursor()
cursor.execute("SET NAMES utf8mb4")

# CTE(WITH 절)를 사용해 가상 테이블을 정의하고 조회하는 쿼리
sql = """
    WITH grade_summary AS (
        SELECT grade, AVG(score) AS avg_score, COUNT(*) AS student_cnt
        FROM student
        GROUP BY grade
    )
    SELECT grade, avg_score, student_cnt
    FROM grade_summary
    WHERE student_cnt >= 5;
"""

cursor.execute(sql)
column_names = [col[0] for col in cursor.description]
results = cursor.fetchall()

print("칼럼명:", column_names)
print("--- 5명 이상 소속된 우수 학년 통계 (CTE 활용) ---")
for row in results:
    print(f"학년: {row[0]}학년, 평균점수: {row[1]:.2f}점, 학생수: {row[2]}명")

mysql.close()

```

### 📊 실행 결과 예시

```text
칼럼명: ['grade', 'avg_score', 'student_cnt']
--- 5명 이상 소속된 우수 학년 통계 (CTE 활용) ---
학년: 1학년, 평균점수: 84.50점, 학생수: 12명
학년: 2학년, 평균점수: 88.20점, 학생수: 10명

```

## 💡 요약

* **`CASE WHEN`**: SQL문 내부에서 조건에 따라 값을 분기하여 새로운 칼럼처럼 출력할 때 사용한다.
* **인라인 뷰 & 서브쿼리**: 쿼리 안에서 임시 가상 테이블처럼 활용해 연산 효율을 높인다.
* **뷰(View) & CTE(`WITH`)**: 복잡한 쿼리를 영구 저장(`CREATE VIEW`)하거나, 임시로 이름을 붙여 가독성을 극대화(`WITH` 절)하는 가상 테이블 활용 기법이다.
