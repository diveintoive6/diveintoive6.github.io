## 1. 문자열 심화 기능 및 메서드

### ① 길이 및 타입 변환
* **`len()` 내장 함수**: 파라미터로 전달된 변수의 길이를 측정해서 반환합니다. 문자열에 사용 시 **글자 수**를 의미하며, 공백 문자나 특수문자(쉼표, 마침표 등)도 1글자로 포함하여 카운트합니다. (연속성 자료형 모두 호환 가능)
* **`str()` 내장 함수**: 파라미터로 전달된 변수를 문자열로 변환합니다.

### ② 검색 및 위치 찾기
* **`count()`**: 문장 속에서 특정 글자나 단어의 개수를 카운트합니다.
* **`find()`**: 특정 글자나 단어가 **처음** 나타나는 위치(인덱스)를 조회합니다. (찾는 값이 없으면 `-1` 반환)
* **`rfind()`**: 특정 글자나 단어가 **마지막**으로 나타나는 위치(인덱스)를 조회합니다. (찾는 값이 없으면 `-1` 반환)

### ③ 대·소문자 여부 검사 및 변환
* **검사 메서드**: `isupper()` (대문자로만 구성된 경우 True), `islower()` (소문자로만 구성된 경우 True)
* **변환 메서드**: 
  * `upper()` / `lower()`: 대문자 또는 소문자로 변환한 **새로운 결과 리턴** (원본 문자열은 변하지 않음. *참고로 파이썬에서 새로운 결과가 안 나오면 원본 객체 자체가 바뀐 것으로 보면 됩니다.*)
  * `swapcase()`: 대문자는 소문자로, 소문자는 대문자로 상호 변환합니다.
  * `capitalize()`: **문장의 첫 글자만** 대문자로 변환하고, 나머지 모든 글자는 소문자로 처리합니다.
  * `title()`: **각 단어의 첫 글자**를 대문자로 변환합니다.
  > ⚠️ **주의:** 문장 전체의 첫 글자만 바꾸는 `capitalize()`와 각 단어의 첫 글자를 바꾸는 `title()`은 결과가 다르므로 명심해야 합니다!

```python
mystr = 'hello python'
print(mystr.swapcase())   # HELLO PYTHON
print(mystr.capitalize()) # Hello python
print(mystr.title())      # Hello Python

```

### ④ 공백 제거 및 기타 조작

* **공백 지우기**: `strip()` (앞뒤 공백), `lstrip()` (왼쪽 공백), `rstrip()` (오른쪽 공백)
* **문자열 바꾸기 (`replace`)**: `문자열객체.replace("원본값", "변경할값")` 형태로, 원본값을 모두 찾아 변경할 값으로 치환한 결과를 리턴합니다. (원본은 유지됨)
* **문자열 자르기 (`split`)**: 전달된 기준값을 사용하여 문자열을 잘라낸 후 **리스트**로 변환합니다.
* **숫자 검사 (`isnumeric`)**: 문자열이 숫자로만 구성된 경우 `True`, 그렇지 않으면 `False`를 반환합니다.

## 2. 딕셔너리 (Dictionary)

중괄호 `{}` 안에 콤마(`,`)로 구별하여 여러 개의 값을 **`"Key : Value"`** 형태로 나열하는 자료구조입니다. 이름을 `Key`, 값을 `Value`라고 부르며 쌍으로 구성됩니다.

### ① 원소 접근 및 확장

* **접근하기**: 변수 이름 뒤에 대괄호를 추가하고 key의 이름을 문자열로 지정합니다. (`print(변수이름["key"])`)
* *주의: 존재하지 않는 Key는 사용할 수 없으며 출력이나 연산 시 오류가 발생합니다.*


* **확장하기**: 존재하지 않는 키에 새로운 값을 할당하면 딕셔너리가 확장됩니다.
```python
foo = {"a": 100, "b": 200}
foo["c"] = 300  # 확장 발생
print(foo)      # {'a': 100, 'b': 200, 'c': 300}

```


* **Key 중복 제한**: 키가 중복될 경우 하나를 제외하고 나머지는 무시됩니다. (보통 나중에 정의된 항목이 이전에 정의된 항목을 덮어씁니다.)

### ② 계층 구조 및 복잡한 형태

기본 데이터 타입뿐만 아니라 리스트나 또 다른 딕셔너리를 포함하여 트리 구조로 계층화할 수 있습니다.

```python
# 리스트를 포함하는 형태
변수이름 = {"key": [value1, value2, value3]}
# 접근 방법: 변수이름["key"][index-number]

# 딕셔너리 안의 딕셔너리 (계층형 목록 구조)
phone = {
    "apple": {
        "name": "iPhone",
        "price": "200$"
    },
    "samsung": {
        "name": "Galaxy",
        "price": "200만원"
    }
}

```

### ③ 주요 메서드 및 함수

* **`len()` / `del**`: 연속성 자료형(문자열, 리스트, 튜플, 딕셔너리 등) 전체에서 원소 개수 카운트 및 특정 원소 삭제 시 사용 가능합니다.
* **`get("key")`**: Key를 통한 간접 접근 방식으로, 존재하지 않는 Key에 접근해도 오류가 발생하지 않고 **`None`을 반환**합니다.
* **`keys()` / `values()**`: Key 혹은 Value만 모아서 각각 `dict_keys`, `dict_values` 객체로 반환하며, `list()`로 감싸 리스트 형태로 변환할 수 있습니다.
```python
성적표 = {"국어": 92, "수학": 88, "영어": 72}
keyList = list(성적표.keys()) # ['국어', '수학', '영어']

```


* **`update()`**: 다른 딕셔너리를 전달받아 기존 딕셔너리에 결합하여 확장합니다.
* **`copy()`**: 리스트와 마찬가지로 딕셔너리 대입은 얕은 복사가 발생하므로, 완전한 독립 복사(깊은 복사)를 위해 `copy()` 메서드를 사용합니다.
* **`clear()`**: 모든 원소를 지우고 빈 딕셔너리만 남깁니다.

## 3. 예외 처리 (Exception Handling)

### ① 에러의 종류

* **문법 에러 (Syntax Error)**: 프로그래밍 언어의 작성 규칙을 지키지 않아 발생합니다. 컴파일러나 인터프리터가 위치를 정확히 알려주므로 IDE를 통해 쉽게 해결할 수 있습니다.
* **런타임 에러 (Runtime Error = 예외)**: 문법적 오류는 없지만 실행 과정에서 예상치 못한 논리적 오류로 인해 발생하며, 프로그램의 비정상 종료를 유발합니다.
* *대표적인 케이스*: 0으로 나누는 경우 (`ZeroDivisionError`), 리스트 범위를 초과하는 인덱스 접근 (`IndexError`) 등



### ② `try ~ except` 문법 활용

예외가 발생하더라도 프로그램이 강제로 중단되지 않고 안전하게 처리되도록 제어합니다.

```python
try:
    # 예외 상황이 예상되는 코드
    num = int(input("숫자를 입력하세요: "))
    result = 10 / num
except ZeroDivisionError as e:
    # 0으로 나누었을 때 발생하는 에러 대응 (as 변수명으로 에러 메시지 저장)
    print(f"0으로 나눌 수 없습니다. 에러내용: {e}")
except IndexError as e:
    # 리스트 인덱스 범위 초과 에러 대응
    print(f"인덱스 범위를 초과했습니다. 에러내용: {e}")
except Exception as e:
    # 앞서 지정하지 않은 모든 예외 상황을 통합해서 대응하는 최상위 클래스
    print(f"알 수 없는 예외가 발생했습니다: {e}")
finally:
    # 에러 발생 여부와 상관없이 항상 마지막에 실행되는 블록
    # (예: 파일 읽기/쓰기 후 close(), 네트워크 연결 해제 등 객체 반납 처리에 사용)
    print("프로그램 작업을 마무리합니다.")

```

> **요약 포인트**
> * 에러 상황을 세분화하여 개별 대응할 수 있으며, 통합 대응이 필요할 때는 최상위 클래스인 `Exception` 하나만 사용할 수도 있습니다.
> * `finally` 블록은 특별히 정리할 작업이 없다면 생략이 가능합니다.
