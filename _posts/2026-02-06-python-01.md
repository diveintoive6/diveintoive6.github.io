파이썬(Python)의 핵심 기초 개념인 **특징, 변수, 자료형, 연산자, 함수, 그리고 입출력**에 대해 정리한 내용입니다.

---

## 1. 파이썬의 주요 특징

* **인터프리터 방식 사용**: 컴파일러를 거치지 않고 코드를 한 줄씩(Line-by-Line) 바로 실행합니다.
* **객체 지향 특징**: 파이썬에서 다루는 모든 데이터와 구조가 객체(Object) 기반입니다.
* **다양한 활용 영역**: 
  * 코딩 테스트 (알고리즘 구현)
  * 웹 프로그래밍 (Django, Flask)
  * 데이터 분석 및 머신러닝 (Pandas, Scikit-learn, SciPy)
* **높은 타입 자유도**: 변수에 타입을 명시하지 않아도 되므로 빠른 프로토타입 개발과 높은 생산성을 제공합니다.
* **실행 속도의 한계**: 컴파일 언어에 비해 상대적으로 실행 속도가 느립니다.
* **GIL(Global Interpreter Lock) 특성**: 멀티 스레딩이 부분적으로만 가능하여, 병렬 처리가 필요할 때는 주로 **멀티 프로세싱**을 활용합니다.

## 2. 변수 (Variable)

변수란 **데이터를 저장하기 위해 프로그램에 의해 이름을 부여받은 메모리 공간**을 의미합니다.

* 파이썬에서는 대입 연산자(`=`)를 사용하여 오른쪽의 값을 왼쪽의 변수 이름에 할당합니다.
* 문법 형식: `변수이름 = 값`

```python
# 변수 초기화 예시
pi = 3.14
money = 12000

# 다른 변수의 값 복사
a = 3
b = a

# 변수 값의 교환 (Swap) - 파이썬만의 강력한 특징
a, b = 1, 2
a, b = b, a  # a는 2, b는 1이 됨

```

---

## 3. 자료형 (Data Type)

변수에 저장되는 데이터의 종류와 특징입니다. 파이썬에서는 변수를 사용하기 전 초기화 과정이 반드시 필요합니다.

| 자료형 | 설명 | 예시 |
| --- | --- | --- |
| **None** | 값이 저장되지 않은 빈 상태 (메모리 공간만 할당) | `None` |
| **int** | 정수 (Integer) | `32`, `-5`, `0` |
| **float** | 실수 (Floating-point) | `3.14`, `-0.001` |
| **bool** | 논리형 (Boolean - 참/거짓) | `True`, `False` (`1`, `0`으로도 표현 가능) |
| **string** | 문자열 (쌍따옴표 `""` 또는 푑따옴표 `''`로 감싼 텍스트) | `"Hello"`, `'Python'` |
| **complex** | 복소수 (실수부 + 허수부, 실무에서 잘 쓰이지 않음) | `1 + 2j` |

### 비어있는 변수 선언하기

```python
hello = None
print(hello)  # 출력: None

```

## 4. 연산자 (Operators)

연산자란 프로그램에서 연산을 수행하기 위해 사용되는 특수 기호입니다.

### (1) 대입 연산자 (`=`)

우변의 값을 좌변의 변수에 대입합니다. 수학에서의 '같다'라는 의미와는 다릅니다.

### (2) 산술 연산자

| 연산자 | 설명 | 예시 |
| --- | --- | --- |
| `+` | 덧셈 | `3 + 2 = 5` |
| `-` | 뺄셈 | `5 - 2 = 3` |
| `*` | 곱셈 | `3 * 4 = 12` |
| `**` | 거듭제곱 | `2 ** 5 = 32` |
| `/` | 나눗셈 (실수 결과 반환, 무한소수 오차 발생 가능) | `10 / 3 = 3.3333...` |
| `//` | 나눗셈의 몫 (정수 부분만 반환) | `10 // 3 = 3` |
| `%` | 나눗셈의 나머지 | `10 % 3 = 1` |

> **Tip**: 정수와 실수를 함께 연산하면, 정수가 자동으로 실수형으로 변환되어 결과도 실수가 됩니다. (모든 수는 0으로 나눌 수 없습니다.)

### (3) 단항 연산자 (복합 대입 연산자)

어떤 변수의 연산 결과를 다시 그 변수 자신에게 대입할 때 사용하는 약식 표현입니다. (`+=`, `-=`, `*=`, `/=`, `//=`, `%=`)

```python
x = 100
x += 5  # x = x + 5 와 동일 (결과: 105)

```

### (4) 비교 연산자 (관계 연산자)

두 값의 크고 작음이나 같음을 비교하여 논리값(`True` / `False`)을 반환합니다.

* 같다: `==`
* 다르다: `!=`
* 초과 / 이상 / 미만 / 이하: `>`, `>=`, `<`, `<=`

### (5) 논리 연산자

* `and`: 양쪽 모두 참일 때 `True`
* `or`: 한쪽이라도 참이면 `True`
* `not`: 논리값을 반전시킴 (`True` ↔ `False`)

### (6) 항등 연산자 vs 완전 항등 연산자

* `==` / `!=`: **데이터 타입에 상관없이** 내용이 같으면 `True` (예: `1 == 1.0`은 `True`)
* `is` / `is not`: **데이터 타입까지 완전히 일치해야** `True` (예: `1 is 1.0`은 `False`)

### (7) 연산자 우선순위

> `괄호(())` $\rightarrow$ `지수(**)` $\rightarrow$ `증감(+, - 단항)` $\rightarrow$ `곱하기/나눗셈(*, /, //, %)` $\rightarrow$ `더하기/빼기(+, -)` $\rightarrow$ `비교연산자` $\rightarrow$ `not` $\rightarrow$ `and` $\rightarrow$ `or`

## 5. 함수 (Function)

특정 기능(연산)을 그룹화하여 재사용하기 위한 코드 단위입니다.

* **구문 형식**:

```python
def 함수이름(파라미터):
    # 들여쓰기(Tab 또는 Space 4칸)를 사용하여 함수에 속한 블록을 표현합니다.
    연산식...

```

* **함수 호출**: 정의된 함수는 반드시 소스코드상에서 **정의가 호출보다 선행**되어야 합니다.
* 형식: `함수이름(파라미터)`


* **내장 함수(Built-in Functions)**: 파이썬이 기본으로 제공하는 함수
* 예시: `print()`, `type()` 등
* `t = type(변수)` 를 실행하면 변수의 자료형 정보가 `<class 'int'>` 형태 등으로 `t`에 저장됩니다.

## 6. 사용자 입력받기 (`input()`)

* 키보드로 입력한 내용을 **무조건 문자열(String) 타입**으로 입력받습니다.
* 형식: `변수이름 = input("표시할 메시지 내용")`

```python
# 문자열 연결 (덧셈 연산만 가능)
s = "Hello" + "Python"
print(s)  # 출력: HelloPython

```

### 문자열 타입 변환하기

`input()`으로 입력받은 숫자를 가지고 산술 연산(더하기 등)을 수행하려면 **형 변환 함수**를 거쳐야 합니다.

* 정수로 변환: `int()` (단, `"a"`, `"가"`처럼 숫자로 변환할 수 없는 경우 에러 발생)
* 실수로 변환: `float()`

```python
# 예시: 숫자 입력받아 더하기
user_input = input("숫자를 입력하세요: ")
number = int(user_input)  # 문자열 -> 정수 변환
print(number + 10)

```
