파이썬에서 **객체(Object)**의 개념과 모든 변수가 객체로 이루어져 있다는 특징, 그리고 문자열을 다루는 다양한 방법(슬라이싱, 포메팅 등)에 대해 알아봅니다.

## 1. 객체 (Object)

* **객체란?** 필요에 따라 다른 변수와 함수를 내장하고 있는 특수한 변수입니다.
* **현실세계의 반영:** 객체의 의미는 "현실세계에 존재하는 것"을 뜻합니다.
* **객체지향 언어:** 객체가 중심이 되는 프로그래밍 언어를 의미하며, 즉 *"현실세계에 존재하는 것을 프로그래밍 언어로 표현한 것"*으로 정의될 수 있습니다.
* **특징:** 특정 기능을 명사적 특성과 동사적 특성으로 구분하여 정의합니다.

> **예시: 회원(Member)**
> * **명사적 특성 (= 멤버 변수):** 아이디, 이메일 주소 등
> * **동사적 특성 (= 메소드, 함수):** 가입(`def join()`), 로그인(`def login()`) 등

### 객체의 사용
객체는 `"객체이름.변수"` 혹은 `"객체이름.함수()"` 형식으로 접근하여 사용할 수 있습니다.

```python
print(member.userid)
member.join()
member.login()

```

## 2. 파이썬의 모든 변수는 객체

파이썬에서는 모든 변수가 객체 형태로 존재합니다. 그러므로 우리가 생성하는 모든 변수는 파이썬에 의해 멤버 변수와 메서드가 자동으로 내장됩니다.

### 리스트 객체의 주요 메서드 예시

* **주어진 값과 일치하는 원소의 개수 세기**
```python
mylist.count(2)

```


* **특정 원소가 처음으로 나타나는 위치 찾기**
```python
mylist.index(10)

```


* **리스트 맨 뒤에 원소 추가 (`append`)**
```python
mylist.append(4)

```


* **리스트 원소 추출 (`pop`: 맨 마지막 요소를 꺼내서 리턴하고 원본에서는 삭제)**
```python
mylist.pop()

```


* **원소 삽입 (`insert`)**: `1`번째 위치에 `10` 삽입 (기존 항목들은 뒤로 밀려남, 맨 앞은 `0`)
```python
mylist.insert(1, 10)

```


* **리스트 확장 (`extend`)**: `mylist2`를 `mylist` 뒤에 이어서 삽입
```python
mylist.extend(mylist2)

```


* **원소 삭제 (`remove`)**: 리스트에서 가장 먼저 오는 `10`을 삭제
```python
mylist.remove(10)

```


* **순서 뒤집기 (`reverse`)**: 원소의 순서를 뒤집음 (원본 자체가 변경됨)
```python
mylist = [1, 7, 5, 3, 9]
mylist.reverse()
print(mylist)  # 출력: [9, 3, 5, 7, 1]

```

## 3. 리스트 원소의 정렬 (오름차순 / 내림차순)

리스트의 원소를 오름차순(순차) 또는 내림차순(역순)으로 정렬하며, **원본 자체가 변경**됩니다.

```python
# 1. 순차 정렬 (오름차순)
mylist = [2, 5, 1, 4, 3]
mylist.sort()
print(mylist)  # 출력: [1, 2, 3, 4, 5]

# 2. 역순 정렬 (내림차순)
mylist = [2, 5, 1, 4, 3]
mylist.sort(reverse=True)
print(mylist)  # 출력: [5, 4, 3, 2, 1]

```

## 4. 문자열과 리스트의 상호 변환

### 문자열을 잘라서 리스트로 변환 (`split`)

문자열 객체에 포함된 함수를 사용하여 특정 글자를 기준으로 잘라낼 수 있습니다.

```python
text = "Hello, Python,World, Good"
mylist = text.split(",")
print(mylist)  # 출력: ['Hello', 'Python', 'World', 'Good']

```

### 리스트를 문자열로 결합 (`join`)

```python
# 특정 기호("$")로 연결하기
dl = "$"
mylist = ['Hello', 'Python', 'World', 'Good']
text = dl.join(mylist)
print(text)  # 출력: Hello$Python$World$Good

# 기호 없이 연결하기
empty = ""
text = empty.join(mylist)
print(text)  # 출력: HelloPythonWorldGood

# 공백으로 연결하기
space = " "
text = space.join(mylist)
print(text)  # 출력: Hello Python World Good

```

## 5. 문자열의 기본 특성

문장을 표현하는 글자들의 모임으로, 반드시 쌍따옴표(`"`)나 홑따옴표(`'`)의 쌍으로 문장을 감싸야 합니다 (따옴표 혼용 불가).

```python
msg1 = "Life is too short"
msg2 = 'You need Python'
print(msg1)
print(msg2)

```

* **반복문 탐색:** 문자의 배열(리스트)이므로 반복문으로 모든 글자 탐색이 가능합니다.
```python
mymsg = "Hello"
for m in mymsg:
    print(m)  # H, e, l, l, o 가 한 줄씩 출력

```


* **연산 제한:** 문자열 간의 연산은 덧셈(`+`, 연결)과 곱셈(`*`, 반복)만 가능합니다.
* 쌍따옴표를 여러 개 넣고 싶을 때는 이스케이프 문자(`\`)를 사용해야 합니다.

## 6. 이스케이프 문자 (Escape String, 확장문자)

문자열에 포함되는 특수문자로, 터미널과 프린터의 줄 바꿈 및 탭 이동 등을 지정합니다. 역슬래시(`\`)와 기호/글자를 조합하여 사용합니다.

| 기호 | 의미 |
| --- | --- |
| `\n` | 줄 바꿈 (=개행문자) |
| `\t` | 탭 (띄어쓰기 4개) |
| `\"` | 쌍따옴표 |
| `\'` | 홑따옴표 |
| `\\` | 역슬래시 자체 |

## 7. 문자열 인덱스 번호와 슬라이싱

### 인덱스 번호

* 각각의 글자들에게 부여되는 `0`부터 시작되는 일련번호입니다.
* 공백(띄어쓰기)도 하나의 글자로 처리됩니다.

### 문자열 슬라이싱 (구간 지정)

대괄호 `[]` 안에 시작 위치와 끝 위치를 콜론(`:`)으로 구분하여 지정합니다.

> **구조:** `문자열변수[시작위치:끝위치]`
> ※ 지정된 **끝위치의 왼쪽 글자 전까지만** 슬라이싱됩니다.

```python
msg = "Life is too short"

# 1. 양의 정수 인덱스 번호를 사용하여 "need" 추출하기
# (실제 문자열 예시와 맞춘 구간 예시)
print(msg[4:8]) 

# 2. 음의 정수 인덱스 번호 사용하기
print(msg[-11:-7])

```

## 8. 문자열 포메팅과 형식 문자

특정 값이 치환될 형식 문자를 포함한 문자열의 형식(format)을 미리 정해 놓고, 형식 문자에 특정 변수 값을 적용하여 완성된 문자열을 만드는 방법입니다.

### 주요 형식 문자

* `%d`: 10진 정수
* `%f`: 10진 실수 (소수점 포함)
* `%s`: 문자열
* `%o`: 8진 정수
* `%x`: 16진 정수
* `%%`: `%` 자체

### 기본 사용 방법

```python
str_format = "나는 %d세 입니다."
print(str_format % 20)  # 출력: 나는 20세 입니다.

```

### 정수 및 문자열 자릿수 표현

* `%5d`: 5자리로 맞추어 오른쪽 정렬 (부족한 자릿수는 공백)
* `%05d`: 5자리로 맞추어 오른쪽 정렬 (부족한 자릿수는 `0`으로 채움)
* `%10s`: 10자리로 맞추어 오른쪽 정렬 (부족한 자릿수는 공백)

### 실수 자릿수 표현 (반올림 처리)

* `%0.3f`: 전체 자리수 제한 없이 소수점 셋째 자리까지 출력
* `%10.3f`: 전체 10자리, 소수점 이하 셋째 자리까지 (오른쪽 정렬, 공백 채움)
* `%010.3f`: 전체 10자리, 소수점 이하 셋째 자리까지 (오른쪽 정렬, `0` 채움)

## 9. 인덱스 번호 및 이름을 사용한 문자열 포메팅 (`.format()`)

### ① 인덱스 번호 사용

`{숫자}` 형식의 치환문자를 사용하며, 숫자값은 `0`부터 시작합니다.

```python
fmt = "이 과자는 {0}{1} 입니다."
rst = fmt.format(2000, "원")
print(rst)  # 출력: 이 과자는 2000원 입니다.

```

### ② 인덱스 이름 사용

인덱스 번호 대신 `{이름}` 형식의 치환문자를 사용할 수 있습니다. 파라미터 전달 순서는 결과에 영향을 주지 않습니다.

```python
fmt = "이 과자는 {price}{unit} 입니다."
rst = fmt.format(unit="원", price=2000)
print(rst)  # 출력: 이 과자는 2000원 입니다.

```
