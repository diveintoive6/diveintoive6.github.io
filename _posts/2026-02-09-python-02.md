## 1. 함수 (Function)

함수란 자주 사용하는 명령어를 재사용하기 위해 그룹화해 놓은 코드 단위입니다. 정의하는 것만으로는 동작하지 않으며, **반드시 호출**해야 실행됩니다.

* **기본 정의 및 호출**
```python
def 함수이름(파라미터):
    # 수행할 연산식
    pass

함수이름(값)  # 함수 호출

```


* **파라미터(매개변수)와 기본값 설정**
* 다중 파라미터는 콤마(`,`)로 구분합니다: `def func(x1, x2): ...`
* **기본값 지정 규칙**: 기본값을 지정한 파라미터는 반드시 **가장 뒤쪽**에 와야 합니다.
* ✅ 가능: `def func(a, b=10):`
* ❌ 불가능: `def func(a=10, b):`


* 이름을 지정하여 순서를 바꿔 전달할 수 있습니다: `func(b=5, a=1)`


* **리턴값 (`return`)**
* 연산 결과를 호출된 위치로 반환합니다.
* `return` 키워드를 만나는 즉시 함수 실행이 종료됩니다. (이후 코드는 실행되지 않음)


* **변수의 유효범위 (Scope)**
* 함수 밖에서 선언한 변수는 함수 내부에서 식별 가능하지만, 함수 내부에서 선언한 지역 변수는 함수 밖에서 식별할 수 없습니다.

## 2. 조건문 (`if`, `elif`, `else`)

특정 조건을 충족할 경우에만 블록 내부의 구문을 실행합니다.

* **기본 구조**
```python
if 조건식:
    실행할 구문
elif 다른조건식:
    실행할 구문
else:
    반대 경우에 실행할 구문

```


* **들여쓰기(Indentation) 주의사항**
* 파이썬은 중괄호(`{}`) 대신 **들여쓰기**로 블록을 구분합니다.
* Tab 키와 Space 키를 혼용하면 에러가 발생하므로, **Tab 키**로 들여쓰기를 통일하는 것이 안전합니다.
* `elif`는 순서대로 판별하며, 가장 먼저 참(`True`)이 나오는 블록 하나만 실행한 뒤 전체 조건문을 빠져나갑니다.


* **참(True)과 거짓(Falsy) 판별 기준**
| 구분 | 참 (`True`) | 거짓 (`False`) |
| --- | --- | --- |
| **논리형** | `True` | `False` |
| **숫자형** | `0`이 아닌 모든 숫자 (`1`, `-5`, `3.14` 등) | `0` |
| **문자열** | 비어있지 않은 문자열 (`" "`(공백 포함)) | 빈 문자열 (`""`) |

## 3. 반복문 (`while`, `for`)

주어진 조건이 참인 동안 또는 지정된 범위 내에서 반복 수행합니다. (파이썬에는 `do-while`, `until` 문이 없습니다.)

### (1) `while` 문

조건식이 참(`True`)인 동안 계속 반복합니다. 조건식이 영원히 참이면 **무한루프**에 빠지므로 증감식이나 종료 조건을 잘 설정해야 합니다.

### (2) `for` 문과 `range()`

지정된 범위 안에서 반복 수행합니다. `range()` 함수를 주로 사용합니다.

* `range([시작값,] 종료값 [,증가값])`
* **중요**: 끝값은 **포함되지 않습니다.** (예: `range(1, 10)`은 1부터 9까지 반복)
* 시작값 생략 시 `0`부터 시작, 증가값 생략 시 `+1`씩 증가합니다.


* **반복 제어 (`break`)**: 반복문 도중 `break`를 만나면 반복을 즉시 강제 종료합니다.

## 4. 자료 구조: 리스트 (List)

리스트는 여러 개의 데이터를 순서대로 담아 관리하는 사물함 형태의 자료구조입니다. 서로 다른 데이터 타입도 하나의 리스트에 함께 담을 수 있습니다.

* **생성 방법**
```python
cheolsu = [75, 82, 91]
mixed_list = [1, "hello", True, 3.14]  # 서로 다른 타입 가능

```


* **리스트 연산**
* 덧셈(`+`): 두 리스트를 연결합니다. (`[1, 2] + [3, 4] -> [1, 2, 3, 4]`)
* 곱셈(`*`): 리스트를 정수배만큼 반복합니다. (`[1, 2] * 3 -> [1, 2, 1, 2, 1, 2]`)


* **2차원 리스트**
* 리스트의 원소로 또 다른 리스트가 들어가는 구조입니다. (`행 -> 열` 순서로 접근)
* 각 행의 열 개수가 달라도 되는 **가변 리스트** 구성이 가능합니다.


```python
my_list = [[1], [10, 20], [100, 200, 300]]

```


* **인덱싱 (Indexing)**
* 정방향 인덱스는 `0`부터 시작하고, 역방향 인덱스는 `-1`부터 시작합니다.


```python
mylist = [10, 20, 30, 40, 50]
# 정방향: 0(10), 1(20), 2(30), ...
# 역방향: -5(10), -4(20), ..., -1(50)

```


* **슬라이싱 (Slicing)**
* `[시작인덱스 : 끝인덱스]` 형태로 범위를 지정합니다.
* **끝 인덱스 위치의 직전 원소까지만** 포함됩니다. (판디스 `iloc`과 동일한 방식)


```python
mylist = [10, 20, 30, 40, 50]
print(mylist[1:4])     # [20, 30, 40] (1, 2, 3번째 인덱스)
print(mylist[-4:-1])   # [20, 30, 40]
print(mylist[:3])      # 처음부터 3번째 전까지 [10, 20, 30]
print(mylist[2:])      # 2번째부터 끝까지 [30, 40, 50]

```


* **슬라이싱을 이용한 원소 삭제**
* 슬라이싱 범위에 빈 리스트(`[]`)를 대입하면 해당 구간의 원소들이 삭제됩니다.


```python
bar = [11, 22, 33, 44, 55]
bar[1:4] = []  # 인덱스 1, 2, 3 위치의 원소 삭제
print(bar)     # [11, 55]

```
