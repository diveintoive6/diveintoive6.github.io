## 1. NumPy (Numerical Python) 라이브러리란?

* 데이터 분석의 출발점이 되는 **빠르고 효율적인 연산 처리 도구**입니다.
* Pandas, Matplotlib, SciPy, Scikit-learn 등과 함께 사용되어 데이터 분석의 핵심 기반을 이룹니다.
* 터미널 명령어를 통해 설치할 수 있습니다:
  ```bash
  pip install --upgrade numpy
  ```

### 주요 역할 및 특징
1. **표 형태 데이터 처리**: 엑셀처럼 표 형태의 데이터를 다루지만 훨씬 빠르며, 복잡한 연산을 쉽게 처리할 수 있습니다.
2. **리스트의 단점 보완**: 
   * 데이터 분석의 전제 조건은 컴퓨터가 이해할 수 있도록 데이터를 숫자 형식으로 변환하는 것입니다.
   * 파이썬의 기본 `list` 자료형은 데이터의 크기가 커질수록 저장 및 가공에서 효율성을 보장하지 못합니다. NumPy는 이러한 단점을 보완합니다.
3. **주요 기능**: 배열(array) 생성 및 연산, 수학 함수(평균, 표준편차, 합계 등), 행렬 계산(벡터·행렬 곱셈), 난수 생성(모의실험, 샘플링)

## 2. NumPy의 핵심 자료구조: `ndarray`

### 일반 배열과 NumPy 배열(`ndarray`)의 비교
* **일반적인 프로그래밍 언어에서의 배열**: 엑셀과 같이 가로(행)와 세로(열)로 데이터를 정리해 놓은 구조로, 같은 종류의 데이터 묶음입니다. (예: 학생들의 시험점수 `[80, 90, 70, 100]`)
* **NumPy의 배열 (`ndarray`)**: n-차원 배열(n-dimensional array) 객체입니다.
  * 파이썬 리스트보다 처리 속도가 빠르고 메모리를 적게 사용합니다.
  * 동일한 자료형을 한 덩어리로 저장합니다.
  * 수학적 계산(합산, 평균, 행렬 연산 등)을 한 번에 수행할 수 있습니다.

> **💡 참고**: 파이썬에는 일반 프로그래밍에서 말하는 고유의 배열 타입이 없습니다. 따라서 파이썬에서 배열이라는 용어가 사용될 경우 이는 보통 NumPy의 `ndarray`를 의미하며, **파이썬 List 자료형의 업그레이드 버전**으로 이해하면 됩니다.

## 3. 배열 생성 및 기초 활용

리스트를 통해 1차원 배열을 만들 수 있으며, `np.array()` 메서드를 사용합니다.

```python
import numpy as np

mydata = np.array([100, 110, 120, 130, 140])
print(type(mydata))  # <class 'numpy.ndarray'>
```

* **배열의 크기**: `len(mydata)`
* **인덱싱 및 슬라이싱**: 리스트와 동일하게 동작합니다. (슬라이싱 시 마지막 번호는 포함되지 않음)
* **반복문을 통한 탐색**:
  ```python
  for i, v in enumerate(mydata):
      print(f"{i}번째 원소 >> {v}")
  ```

## 4. `ndarray`의 특성과 데이터 타입

### (1) 원소 타입의 통일
* **List 타입**: 서로 다른 데이터 타입의 원소를 허용합니다. (예: `[100, 3.14, True]`)
* **ndarray 타입**: 가장 포괄적인 데이터 타입 하나만 허용합니다. 서로 다른 타입이 섞여 있으면 가장 포괄적인 형태(예: 실수형)로 자동 변환됩니다.
  ```python
  mylist = [100, 3.14, True]
  myarr = np.array(mylist)
  print(myarr)  # [100.    3.14    1.   ] (실수형으로 통일됨)
  ```

### (2) `dtype` 파라미터를 통한 강제 타입 지정
생성 과정에서 `dtype`을 지정하여 타입을 강제할 수 있습니다. (실수를 정수로 변환 시 소수점 아래는 버려집니다.)
```python
mylist1 = [100.12, 3.14, 1.5]
myarr1 = np.array(mylist1, dtype='int')
print(myarr1)  # [100   3   1]
```

### (3) 문자열이 포함된 경우
문자열은 표현 범위가 가장 넓기 때문에, 리스트에 문자열이 포함되어 있다면 모든 원소가 문자열로 변환됩니다.
```python
mylist2 = [1.2, 3, True, '4']
myarr2 = np.array(mylist2)
print(myarr2)  # ['1.2' '3' 'True' '4']
```

## 5. `list` 타입과의 상호 역변환
`ndarray`와 `list`는 상호 호환이 가능합니다.

```python
mylist3 = [10, 20, 30, 40, 50]
myarr3 = np.array(mylist3)

# ndarray -> list 변환
mylist3_1 = list(myarr3)
print(type(mylist3_1), mylist3_1)
```

## 6. 배열의 연산 및 조건 추출

### (1) 기본 연산
ndarray 연산은 위치가 동일한 원소끼리 이루어집니다. 연산자뿐만 아니라 전용 메서드를 사용할 수도 있습니다.

* 덧셈: `arr1 + arr2` 또는 `np.add(arr1, arr2)`
* 뺄셈: `arr1 - arr2` 또는 `np.subtract(arr1, arr2)`
* 곱셈: `arr1 * arr2` 또는 `np.multiply(arr1, arr2)`
* 나눗셈: `arr1 / arr2` 또는 `np.divide(arr1, arr2)`

### (2) 불리언 인덱싱과 논리 연산
조건에 맞는 위치의 원소만 추출할 수 있습니다.
```python
grade = np.array([1, 2, 3, 4])
bool_array = np.array([True, False, True, False])

result = grade[bool_array]
print(result)  # [1, 3]
```
또한 `np.logical_and()`, `np.logical_or()` 등을 통해 여러 조건을 결합할 수 있습니다.

## 7. 조건 분기 (`np.where`, `np.select`)

### ① `np.where()` (if ~ else 효과)
주어진 조건에 따라 참일 때와 거짓일 때 각각 다른 값을 반환합니다.
```python
exam = np.array([60, 83, 75, 92, 86])

# np.where(조건, 참일 경우 값, 거짓일 경우 값)
result = np.where(exam >= 80, '합격', '불합격')
print(result)  # ['불합격' '합격' '불합격' '합격' '합격']
```

### ② `np.select()` (다중 조건 분기)
if-elif-else 구조처럼 여러 조건을 순차적으로 검사하여 값을 부여할 때 사용합니다.
```python
exam = np.array([60, 85, 51, 79, 94, 88])

# 조건 리스트 설정
conditions = [
    (exam >= 90),  # if
    (exam >= 80),  # elif
    (exam >= 70)   # elif
]

# 각 조건에 대응하는 값 리스트
value = ['A', 'B', 'C']

# np.select(조건 리스트, 값 리스트, default값)
result = np.select(conditions, value, default='F')
print(result)  # ['F' 'B' 'F' 'C' 'A' 'B']
```
> **⭐ 핵심 요약**: `np.where()`와 `np.select()`는 데이터 분석 시 일괄적인 조건 처리를 위해 매우 자주 사용되므로 반드시 기억해 두어야 합니다!
