파이썬 객체지향 프로그래밍(OOP)의 꽃인 **클래스 상속(Inheritance)**의 개념, 부모 클래스에 접근하는 `super()`, 기존 기능을 수정·확장하는 **메서드 오버라이드(Method Override)**, 그리고 여러 클래스를 동시에 상속받는 **다중 상속**에 대해 알아봅니다.

---

## 1. 클래스 상속(Inheritance)의 이해

### ① 상속이란?
* 클래스 간의 **부모와 자식 관계**를 설정하여 코드를 재사용하는 코딩 기법입니다.
* 클래스 A를 클래스 B가 상속받을 때, B는 A의 **모든 멤버 변수와 메서드를 자신의 것으로 상속**받게 됩니다.
  * *단, `__` (private)로 설정된 기능은 은닉되어 상속되지 않습니다.*
* 자식 클래스는 부모로부터 상속받은 기능을 직접 코딩하지 않아도 자신의 것처럼 자유롭게 사용할 수 있습니다.

> **구조:** `class 자식클래스이름(부모클래스이름):`

### ② 기능의 확장으로서의 상속
상속은 단순히 코드를 복사해 오는 것이 아니라 **기능의 확장**을 의미합니다.
```text
Class A  <<-----  Class B  <<-----  Class C
(부모)             (B는 A 상속)       (C는 B 상속)

```

* **클래스 B**는 클래스 A의 기능을 자신의 것으로 사용하면서 추가적인 기능을 구현할 수 있습니다.
* **클래스 C**는 B가 상속받은 A의 모든 기능과 B의 기능을 포함하여 자신의 것으로 확장하여 사용할 수 있습니다.

## 2. 부모 클래스 접근하기 (`super()`)

### ① `super()` 함수란?

* 부모 클래스를 반환하는 내장 함수입니다.
* 자식 클래스에서 부모에게 상속받은 원본 기능을 직접 호출하거나 유지하고자 할 때 사용합니다.

---

## 3. 메서드 오버라이드 (Method Override)

상속받은 부모의 메서드를 자식 클래스가 재정의(Override)하여 행동을 다르게 바꾸는 기법입니다.

### ① 부모의 기능 완전히 수정하기

자식 클래스가 부모와 **동일한 이름의 메서드**를 정의하면, 부모의 메서드가 덮어씌워집니다.

```python
class Animal:
    def sound(self):
        print("동물이 소리를 냅니다.")

class Dog(Animal):
    def sound(self):        # 부모에게 상속받은 sound() 메서드를 재정의(Override)
        print("멍멍!")

a = Animal()
a.sound()  # 출력: 동물이 소리를 냅니다.

d = Dog()
d.sound()  # 출력: 멍멍!

```

### ② 부모의 기능을 유지하면서 추가적인 기능 덧붙이기

부모의 메서드를 오버라이딩하면서도, `super()` 함수를 사용하면 **재정의되기 전의 원본 기능**을 먼저 호출할 수 있습니다.

```python
class Animal:
    def sound(self):
        print("동물이 소리를 냅니다.")

class Cat(Animal):
    def sound(self):
        super().sound()     # 부모의 원본 기능 호출
        print("야옹~")      # 자식만의 추가 기능 구현

c = Cat()
c.sound()
# 출력 결과:
# 동물이 소리를 냅니다.
# 야옹~

```

> **💡 참고 (자바의 오버로딩과 파이썬의 차이)**
> * **메서드 오버로딩(Overloading - 자바 등):** 이름이 같은 메서드이되, 입력되는 매개변수의 형태(타입이나 개수)를 다르게 하여 하나의 객체 안에서 여러 형태로 다루는 기법입니다. (예: `sound(int)`, `sound(str)`)
> * 파이썬은 데이터 타입이나 매개변수 형태를 엄격하게 따지지 않기 때문에 언어 차원에서 오버로딩을 자주 활용하지는 않습니다.

## 4. 클래스 다중 상속 (Multiple Inheritance)

두 개 이상의 부모 클래스를 지정하여 여러 클래스의 기능을 하나의 자식 클래스에 한꺼번에 상속받는 기법입니다.

```python
class Calc(부모클래스1, 부모클래스2, ...):
    # 부모1과 부모2의 모든 멤버 변수와 메서드를 복합적으로 상속받음
    pass

```

* **의의:** 작은 단위의 기능들을 각각 모듈화하고, 이를 조립(다중 상속)하여 풍부한 기능을 가진 복합적인 클래스를 효율적으로 구성할 수 있습니다.

```
