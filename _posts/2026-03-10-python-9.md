판다스(Pandas)로 데이터를 다루다 보면 이미 생성된 데이터프레임에 다른 데이터프레임을 다시 감싸거나, 새로운 리스트 형태의 데이터를 추가해야 하는 상황이 자주 발생합니다.

이번 글에서는 이미 완성된 DataFrame을 다시 `pd.DataFrame()`에 넣었을 때의 동작 원리와, 2차원 구조에 새로운 열(Column) 및 행(Row) 리스트를 추가하는 방법을 명확하게 정리해 보겠습니다.

---

## 1. 데이터프레임을 다시 `pd.DataFrame()`에 넣으면 어떻게 될까?

```python
아이브_앨범들_2 = pd.DataFrame(아이브_앨범들)

```

* **동작 원리:** 이미 만들어진 데이터프레임을 인자로 넘기면, 기존 데이터를 바탕으로 완전히 새로운 데이터프레임 객체(독립된 복사본)가 생성됩니다.
* **특징:**
* `아이브_앨범들_2`를 수정한다고 해서 원본인 `아이브_앨범들`의 값이 함께 바뀌지 않습니다.
* 기존 데이터를 안전하게 백업하거나 형태만 똑같은 새로운 독립 판을 구성하고 싶을 때 유용합니다.



---

## 2. 2차원 데이터프레임에 리스트(열/행)를 추가할 수 있을까?

**네, 당연히 가능합니다!** 판다스는 리스트를 이용해 새로운 세로 줄(열)이나 가로 줄(행)을 아주 간편하게 추가할 수 있습니다.

### ① 새로운 열(Column) 추가하기 (세로 줄 추가)

데이터프레임의 행 개수와 일치하는 길이의 리스트가 있다면, 새로운 컬럼 이름을 지정해 그대로 대입하면 됩니다.

```python
# '작곡가'라는 새로운 컬럼 추가 (데이터 6개짜리 리스트 대입)
아이브_앨범들['작곡가'] = ['라이언전', '서지음', '이들', '켄지', '라이언전', '프로듀서X']

display(아이브_앨범들)

```

### ② 새로운 행(Row) 추가하기 (가로 줄 추가)

행을 추가할 때는 일반 대입(`df[...] = [...]`)이 아니라, 인덱스 라벨을 지정할 수 있는 **`loc` 인덱서**를 사용해야 합니다.

```python
# 'REVIVE2'라는 새로운 인덱스(행) 이름과 함께 리스트 통째로 대입
아이브_앨범들.loc['REVIVE2'] = [7, 105, 70, 5000, '신곡', '싱글', '1번']

display(아이브_앨범들)

```

* **주의점:** `아이브_앨범들['REVIVE2'] = [...]`처럼 작성하면 새로운 '열'로 인식하여 에러가 나거나 의도치 않은 결과가 발생하므로, 반드시 `loc`를 사용해 행 위치를 지정해야 합니다.

## 3. 핵심 요약 비교 표

| 조작 방식 | 코드 예시 | 설명 |
| --- | --- | --- |
| **데이터프레임 복사** | `df_new = pd.DataFrame(df_old)` | 기존 데이터프레임을 기반으로 **완전히 독립된 새 객체** 생성 |
| **새로운 열(Column) 추가** | `df['새컬럼명'] = [리스트]` | 세로 방향(열 단위)으로 새로운 리스트 데이터 추가 |
| **새로운 행(Row) 추가** | `df.loc['새인덱스명'] = [리스트]` | 가로 방향(행 단위)으로 새로운 리스트 데이터 추가 (**반드시 `loc` 사용**) |
