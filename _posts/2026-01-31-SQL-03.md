## 1. 날짜/시간 함수 (Date & Time Functions)

시스템의 현재 시각을 조회하거나, 날짜/시간 타입의 컬럼을 가공·계산할 때 사용합니다.

### 주요 날짜/시간 함수
| 함수명 | 기능 | 예시 및 결과 |
| :--- | :--- | :--- |
| **NOW()** | 현재 날짜와 시간 반환 | `2026-03-12 16:00:00` |
| **CURDATE()** | 현재 날짜만 반환 | `2026-03-12` |
| **CURTIME()** | 현재 시간만 반환 | `16:00:00` |
| **DATE(date)** | 날짜/시간 값에서 날짜만 추출 | `date('2025-04-05 10:23:45')` → `2025-04-05` |
| **TIME(date)** | 날짜/시간 값에서 시간만 추출 | `time('2025-04-05 10:23:45')` → `10:23:45` |
| **YEAR / MONTH / DAY** | 연, 월, 일(day) 성분 추출 | `year('2025-04-05')` → `2025` |
| **DATE_ADD(date, INTERVAL n unit)** | 날짜에 시간/일/월 추가 | `date_add('2025-04-01', interval 7 day)` → `2025-04-08` |
| **DATE_SUB(date, INTERVAL n unit)** | 날짜에서 시간/일/월 차감 | `date_sub('2025-04-05', interval 1 month)` → `2025-03-05` |
| **DATEDIFF(date1, date2)** | 두 날짜의 차이(일 수) 계산 | `datediff('2025-04-10', '2025-04-01')` → `9` |
| **DATE_FORMAT(date, format)** | 지정한 형식의 문자열로 변환 | `date_format('2025-04-05', '%Y년 %m월')` → `'2025년 04월'` |
| **QUARTER(date)** | 날짜에 대한 분기 반환 | `quarter('2025-04-05')` → `2` |

### 📌 DATE_FORMAT 함수의 주요 형식 문자
- `%Y` / `%y`: 4자리 / 2자리 연도
- `%m` / `%M`: 숫자인 월(01~12) / 영문 달 이름
- `%d` / `%e`: 2자리 / 1자리 일(day)
- `%H` / `%h`: 24시간제 / 12시간제 시간
- `%i`: 분, `%s`: 초, `%p`: AM/PM

## 2. 형변환 함수 & 조건 함수

### 형변환 함수 (Data Type Conversion)
데이터의 타입을 강제로 변경할 때 사용합니다.
- `CAST(expr AS type)` : 값을 지정한 타입으로 변환 (예: `CAST('123' AS INT)` → `123`)
- `CONVERT(expr, type)` : CAST와 동일한 기능을 수행 (예: `CONVERT('2025-04-05', DATE)`)

### 조건 함수 (Condition Functions)
상태나 조건에 따라 다른 결과를 반환합니다.
- **`IF(조건, A, B)`**: 조건이 참이면 A, 거짓이면 B를 반환합니다. (예: `IF(gender='M', '남자', '여자')`)
- **`IFNULL(검사할 값, 대체할 값)`**: 검사할 값이 `NULL`인 경우 대체할 값을 반환하고, 아니면 원본값을 유지합니다. (예: `IFNULL(score, 0)`)
- **`NULLIF(expr1, expr2)`**: 두 값이 같으면 `NULL`을, 다르면 첫 번째 표현식의 값을 반환합니다.

## 3. CASE 문 (Conditional Branching)

함수는 아니지만 조건 함수와 동일한 기능을 수행하며, `IF`문보다 더 복잡하고 다중적인 조건 분기를 처리할 수 있습니다.

### 기본 문법
```sql
SELECT 컬럼이름,
       CASE 
           WHEN 조건1 THEN 결과1
           WHEN 조건2 THEN 결과2
           ELSE 결과n
       END AS 별칭
FROM 테이블이름;

```

* 순차적으로 조건을 확인하여 참인 첫 번째 결과를 반환하며, 모든 조건을 만족하지 않으면 `ELSE` 값을 반환합니다. `END`로 구문의 끝을 알립니다.

## 4. 집계 함수 (Aggregate Functions) & GROUP BY

여러 행의 데이터를 하나로 요약하여 합계, 평균, 개수, 최댓값 등을 계산합니다. (**⚠️ 주의: 집계 함수는 `WHERE`절에서 직접 사용할 수 없습니다.**)

### 주요 집계 함수

| 함수명 | 기능 (NULL 자동 제외) |
| --- | --- |
| **COUNT()** | 결과 집합의 전체 행 수 또는 특정 컬럼의 데이터 수 |
| **SUM()** | 숫자들의 합계 계산 |
| **AVG()** | 평균값 계산 |
| **MAX() / MIN()** | 최댓값 / 최솟값 반환 |
| **GROUP_CONCAT()** | 여러 값을 하나의 문자열로 합침 (예: `'홍길동, 김철수'`) |

### GROUP BY절의 사용

기준 컬럼의 값이 같은 데이터끼리 하나의 그룹으로 묶습니다.

```sql
SELECT 기준컬럼, 집계함수(컬럼)
FROM 테이블이름
[ WHERE 검색조건 ]
[ GROUP BY 기준컬럼1, 기준컬럼2 ]
[ HAVING 조건 ] -- 그룹화된 결과 필터링
[ ORDER BY 정렬기준 ];

```

* **핵심 규칙**: `GROUP BY` 절에 명시한 컬럼이나 집계 함수를 적용한 컬럼 외에는 `SELECT` 절에 단독으로 올 수 없습니다.

## 5. 실전 활용 예제 10선

### 예제 1: 가입일 기준 최근 7일 이내 회원 조회 (`NOW`, `DATE_SUB`)

시스템 현재 시각을 기준으로 일주일 전부터 가입한 신규 회원들을 조회합니다.

```sql
SELECT user_id, username, created_at
FROM users
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY);

```

### 예제 2: 날짜 포맷 변환을 통한 주문 통계용 월별 그룹화 (`DATE_FORMAT`)

주문일시(`order_date`)를 `'YYYY-년 MM월'` 형태로 변환하여 월별 통계를 가독성 있게 조회합니다.

```sql
SELECT DATE_FORMAT(order_date, '%Y년 %m월') AS order_month,
       COUNT(*) AS monthly_orders,
       SUM(total_amount) AS monthly_sales
FROM orders
GROUP BY DATE_FORMAT(order_date, '%Y년 %m월');

```

### 예제 3: NULL 데이터 안전한 대체 처리 (`IFNULL`)

고객의 마일리지 점수가 `NULL`인 경우 기본값 `0`으로 치환하여 합산 및 출력합니다.

```sql
SELECT username, 
       IFNULL(mileage, 0) AS safe_mileage
FROM users;

```

### 예제 4: 조건 함수를 활용한 성별 텍스트 변환 (`IF`)

코드성 데이터(`M`, `F`)를 사용자가 읽기 편한 `'남성'`, `'여성'` 형태로 변환합니다.

```sql
SELECT username, 
       IF(gender = 'M', '남성', '여성') AS gender_kr
FROM users;

```

### 예제 5: CASE 문을 활용한 회원 등급 다중 분류 (`CASE WHEN`)

회원의 총 구매 금액에 따라 골드, 실버, 브론즈 등급을 동적으로 부여합니다.

```sql
SELECT username, total_spent,
       CASE 
           WHEN total_spent >= 1000000 THEN 'VIP 골드'
           WHEN total_spent >= 500000 THEN '우수 실버'
           ELSE '일반 브론즈'
       END AS membership_tier
FROM users;

```

### 예제 6: 문자열 형변환을 이용한 조건 검색 (`CAST`)

문자열 타입으로 저장된 상품 코드나 ID를 숫자로 강제 형변환하여 대소 비교를 수행합니다.

```sql
SELECT *
FROM inventory
WHERE CAST(item_code AS INT) BETWEEN 1000 AND 2000;

```

### 예제 7: 부서별 평균 급여 및 최고 급여 집계 (`GROUP BY`, `AVG`, `MAX`)

부서별(`department_id`)로 그룹화하여 소속 직원의 평균 급여와 최고 급여를 구합니다.

```sql
SELECT department_id, 
       ROUND(AVG(salary), 2) AS avg_salary,
       MAX(salary) AS max_salary
FROM employees
GROUP BY department_id;

```

### 예제 8: 조건에 맞는 그룹 데이터 필터링 (`GROUP BY`, `HAVING`)

부서별 평균 급여가 500만 원 이상인 부서들만 필터링하여 조회합니다.

```sql
SELECT department_id, 
       AVG(salary) AS avg_salary
FROM employees
GROUP BY department_id
HAVING AVG(salary) >= 5000000;

```

### 예제 9: 여러 값들을 하나의 문자열로 결합하기 (`GROUP_CONCAT`)

프로젝트별로 참여한 팀원들의 이름을 쉼표로 구분하여 한 줄로 나열합니다.

```sql
SELECT project_id, 
       GROUP_CONCAT(member_name SEPARATOR ', ') AS team_members
FROM project_assignments
GROUP BY project_id;

```

### 예제 10: 날짜 차이 계산을 통한 휴면 계정 판별 (`DATEDIFF`)

마지막 로그인 날짜(`last_login_date`)와 현재 날짜를 비교하여 180일 이상 경과한 계정을 판별합니다.

```sql
SELECT user_id, username, last_login_date,
       DATEDIFF(NOW(), last_login_date) AS inactive_days,
       IF(DATEDIFF(NOW(), last_login_date) >= 180, '휴면 계정', '활성 계정') AS account_status
FROM users;

```

## 6. 마무리 요약

* **날짜/시간 함수**는 로그 분석이나 기간별 통계를 낼 때 필수적이며, 형변환 및 조건 함수(`IF`, `IFNULL`, `CASE`)는 데이터의 예외 상황을 안전하게 처리하고 유연한 출력을 가능하게 해줍니다.
* 집계 함수와 `GROUP BY`는 대용량 데이터를 의미 있는 지표로 요약·분석하는 데이터베이스 핵심 기능이므로 실전 연습을 통해 숙달해 두는 것이 좋습니다.
