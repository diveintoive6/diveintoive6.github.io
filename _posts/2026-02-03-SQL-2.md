데이터베이스를 다루다 보면 가장 골치 아픈 존재 중 하나가 바로 **`NULL`**입니다. 값이 없음을 뜻하는 특수한 데이터이기 때문에 연산이나 집계 시 예상치 못한 결과를 만들어내곤 합니다.

이번 글에서는 MySQL에서 NULL 값을 처리하는 대표적인 함수들(`IFNULL`, `COALESCE`, 오라클 `NVL/NVL2`의 MySQL 대체법인 `CASE문`)을 정리하고, 실무에서 흔히 헷갈리는 **NULL 연산의 특징과 함정**까지 완벽하게 파헤쳐 보겠습니다.

---

## 1. MySQL에서 NULL 처리 함수 쓰기 (`IFNULL`, `COALESCE`, `NVL` 대체)

MySQL에서 NULL 값을 처리하기 위해 사용하는 함수들의 종류와 사용법입니다. 

또한 `NVL`과 `NVL2`는 주로 Oracle에서 사용되는 함수로, MySQL에서는 기본적으로 지원하지 않지만 대체 함수를 통해 동일한 기능을 구현할 수 있습니다.

### ① IFNULL (가장 흔하게 사용)

지정한 표현식이 NULL인지 확인하고, NULL이 아니면 그 값을, NULL이면 지정한 대체값을 반환합니다.

* **문법:** `IFNULL(expression, alt_value)`
* **예시:**

```sql
SELECT IFNULL(commission, 0) FROM employees;

```

`commission`이 NULL이면 `0`을 반환하고, 값이 있으면 해당 `commission` 값을 반환합니다.

### ② COALESCE (표준 SQL 함수)

나열된 인수들 중에서 NULL이 아닌 첫 번째 값을 반환합니다. 2개 이상의 인수를 받을 수 있어 매우 유연합니다.

* **문법:** `COALESCE(val1, val2, val3, ...)`
* **예시:**

```sql
SELECT COALESCE(phone_number, mobile_number, '연락처 없음') FROM users;

```

`phone_number`가 NULL이 아니면 이를 반환하고, NULL이면 `mobile_number`를 확인합니다. `mobile_number`도 NULL이면 `'연락처 없음'`을 반환합니다.


### ③ NVL 대체하기 (MySQL에는 없음)

Oracle의 `NVL(expr1, expr2)`은 MySQL의 `IFNULL(expr1, expr2)`과 정확히 같은 동작을 합니다.


### ④ NVL2 대체하기 (MySQL에는 없음)

Oracle의 `NVL2(expr1, val2, val3)`는 `expr1`이 NULL이 아니면 `val2`를, NULL이면 `val3`를 반환하는 함수입니다. MySQL에서는 `IF` 함수나 `CASE` 문으로 대체할 수 있습니다.

* **문법 (IF 사용):** `IF(expr1 IS NOT NULL, val2, val3)`
* **예시:**

```sql
SELECT IF(commission IS NOT NULL, '지급 대상', '비대상') FROM employees;

```

`commission`이 NULL이 아니면 `'지급 대상'`, NULL이면 `'비대상'`을 반환합니다.


* **`CASE` 문 사용 (더 복잡한 분기나 표준 지향적일 때):**

```sql
SELECT 
    name,
    CASE 
        WHEN commission IS NOT NULL THEN '지급 대상'
        ELSE '비대상'
    END AS commission_status
FROM employees;

```

### 📌 요약 비교표

| 기능 (오라클 기준) | MySQL 대응 함수 | 설명 |
| --- | --- | --- |
| `NVL(A, B)` | `IFNULL(A, B)` 또는 `COALESCE(A, B)` | A가 NULL이면 B 반환 |
| `COALESCE(A, B, C)` | `COALESCE(A, B, C)` | NULL이 아닌 첫 번째 값 반환 |
| `NVL2(A, B, C)` | `IF(A IS NOT NULL, B, C)` | A가 NULL이 아니면 B, NULL이면 C 반환 |

## 2. NULL 연산의 치명적인 함정 ⚠️ (꼭 기억할 포인트)

SQL에서 `NULL`은 '0'이나 '공백("")'과 완전히 다릅니다. "알 수 없는 값(Unknown)"을 의미하기 때문에 연산 규칙이 아주 독특합니다.

### ① 사칙연산 시 결과는 무조건 NULL

NULL이 포함된 산술 연산은 결과가 무조건 `NULL`이 됩니다.

```sql
SELECT 100 + NULL; -- 결과: NULL
SELECT 50 * NULL;  -- 결과: NULL

```

> **해결책:** 계산에 쓰이는 컬럼에 NULL이 올 수 있다면 반드시 `IFNULL(col, 0)` 등으로 감싸주어야 정상적인 연산이 가능합니다.

### ② 집계 함수(SUM, AVG, COUNT 등)에서는 제외됨

데이터를 집계할 때 **NULL 값은 자동으로 연산에서 제외**됩니다.

* **`COUNT(컬럼명)`**: 해당 컬럼의 값이 **NULL인 행은 개수에 포함하지 않습니다.** (반면, 전체 행 개수를 셀 때는 `COUNT(*)`를 사용해야 NULL 여부와 상관없이 전부 카운트됩니다.)
* **`SUM(컬럼명)` / `AVG(컬럼명)**`: NULL 값을 아예 없는 셈 치고 나머지 값들만 가지고 합산 및 평균을 냅니다.

---

### ③ 💡 "SELECT * 시에는 포함되지만, 집계나 연산에서는 제외된다"의 의미

실무 쿼리를 짤 때 이 차이 때문에 버그가 생기기 쉽습니다.

* **전체 조회 (`SELECT *`) 시:**
테이블의 행(Row) 자체를 가져올 때는 특정 컬럼이 NULL이든 말든 **해당 데이터(행) 전체가 조회 결과에 포함**됩니다.
* **집계 및 조건 비교 시:**
하지만 그 데이터를 가지고 연산을 하거나 조건을 걸면 이야기가 달라집니다.
```sql
-- commission이 NULL인 사람도 SELECT * 로 조회하면 행 전체가 나옵니다.
SELECT * FROM employees; 

-- 하지만 집계 함수를 쓰면 NULL은 빠집니다.
SELECT AVG(commission) FROM employees; 
-- (NULL인 직원을 제외한 나머지 직원들의 평균만 계산됨)

-- 만약 NULL인 직원까지 포함해서 '전체 직원수' 기준으로 평균을 내고 싶다면?
SELECT SUM(commission) / COUNT(*) FROM employees; -- 명시적으로 처리해야 함!

```

## 3. SQL COALESCE vs Pandas 결측치 처리 비교 🐼

SQL에서 여러 컬럼의 결측치(`Null`)를 순차적으로 비교하며 대체할 때 `COALESCE` 함수를 사용하셨을 겁니다. 이와 동일한 역할을 파이썬 판다스(Pandas)에서 수행할 때 가장 널리 쓰이는 메서드를 비교해 보겠습니다.

### ① 여러 컬럼을 순서대로 비교 (`COALESCE` 형태)

SQL에서 `COALESCE(col1, col2, col3)`은 첫 번째로 Null이 아닌 값을 찾아 반환합니다. 판다스에서는 이를 **체이닝(Chaining)** 방식으로 구현합니다.

* **SQL 예시:**
```sql
SELECT COALESCE(col1, col2, col3) AS final_val FROM table;

```


* **판다스 예시:**
```python
import pandas as pd
import numpy as np

# 샘플 데이터 생성
df = pd.DataFrame({
    'col1': [1, np.nan, np.nan, np.nan],
    'col2': [np.nan, 2, np.nan, np.nan],
    'col3': [np.nan, np.nan, 3, np.nan]
})

# combine_first를 사용하여 결측치 채우기
df['final_val'] = df['col1'].combine_first(df['col2']).combine_first(df['col3'])

```


*(결과 `df['final_val']`: `[1.0, 2.0, 3.0, NaN]` - 모두 NaN인 마지막 행은 NaN 유지)*

### ② 특정 '단일 값'으로 대체 (`NVL`, `IFNULL` 형태)

SQL에서 `COALESCE(col1, 0)`처럼 결측치를 특정 상수나 지정된 값으로 바꾸고 싶을 때는 **`fillna()`** 메서드가 가장 적합합니다.

* **SQL 예시:**
```sql
SELECT COALESCE(col1, 0) FROM table;

```


* **판다스 예시:**
```python
# 결측치를 0으로 대체
df['col1'] = df['col1'].fillna(0)

```



### 📌 요약 및 선택 가이드

| 상황 | SQL | Pandas |
| --- | --- | --- |
| **여러 컬럼을 순서대로** 비교하며 결측치 채우기 | `COALESCE(A, B, C)` | `A.combine_first(B).combine_first(C)` |
| **하나의 컬럼**의 결측치를 **특정 상수**로 채우기 | `COALESCE(A, 0)` 또는 `IFNULL(A, 0)` | `A.fillna(0)` |



---

## ✨ 한 줄 요약

* **단순 치환:** `IFNULL(col, 대체값)`
* **다중 검사:** `COALESCE(col1, col2, 대체값)`
* **조건부 분기(NVL2 대체):** `IF(col IS NOT NULL, 참값, 거짓값)` 또는 `CASE` 문
* **NULL 연산 주의점:** 사칙연산에 들어가면 결과를 전부 `NULL`로 만들고, 집계 함수(`COUNT(컬럼)`, `SUM`)에서는 알아서 제외되니 주의할 것!
