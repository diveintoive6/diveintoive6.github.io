판다스(Pandas)에서 DataFrame의 데이터를 슬라이싱(범위 추출)할 때 가장 많이 헷갈리면서도 핵심적인 두 가지 메서드가 바로 `loc`와 `iloc`입니다.

결론부터 말하면, 일반적인 파이썬 슬라이싱처럼 **마지막 범위를 미포함하는 것은 `iloc**`, 그리고 유일하게 마지막 범위까지 철저히 포함하는 것은 `loc`입니다.

---

## 1. `loc` vs `iloc` 핵심 비교

| 구분 | `loc` (Location) | `iloc` (Integer Location) |
| --- | --- | --- |
| **기준** | **라벨(Label)** 이름 기준 | **정수 위치(Integer Index)** 기준 |
| **슬라이싱 범위** | **시작점부터 끝점까지 모두 포함 (Inclusive)** | **시작점 포함, 끝점 미포함 (Exclusive)** (일반 파이썬/리스트와 동일) |
| **비유** | "이름표"로 찾기 (예: 'Alice'부터 'Bob'까지) | "몇 번째 칸"으로 찾기 (예: 0번째부터 2번째 전까지) |

---

## 2. `iloc`: 순번(인덱스 번호)으로 접근하기 (일반 파이썬 방식)

`iloc`는 우리가 흔히 아는 파이썬 리스트나 문자열 슬라이싱 규칙을 그대로 따릅니다. 즉, **마지막 번호 직전까지만** 가져옵니다.

```python
import pandas as pd

# 예시 데이터프레임 생성
data = {'이름': ['Alice', 'Bob', 'Charlie'], '나이': [25, 30, 35]}
df = pd.DataFrame(data, index=['a', 'b', 'c'])

# iloc는 정수 인덱스(0부터 시작)를 사용합니다.
print(df.iloc[0:2]) 

```

**출력 결과:**

```text
      이름  나이
a  Alice  25
b    Bob  30

```

* **특징:** `0:2`를 입력했음에도 인덱스 `0`과 `1`번 행만 가져왔습니다. **끝 번호(2번)는 포함되지 않습니다.**

---

## 3. `loc`: 라벨(이름)로 접근하기 (마지막 포함!)

`loc`는 행의 "이름(라벨)"을 기준으로 데이터를 자릅니다. 여기서 아주 중요한 특징이 있습니다. `loc`는 지정한 범위의 마지막 라벨까지 온전히 포함(Inclusive)합니다.

```python
# loc는 인덱스 라벨 문자열('a', 'b')을 직접 사용합니다.
print(df.loc['a':'b'])

```

**출력 결과:**

```text
      이름  나이
a  Alice  25
b    Bob  30

```

* **특징:** `'a'`부터 `'b'`까지 지정했더니, **시작인 'a'뿐만 아니라 끝인 'b' 행까지 모두 출력**되었습니다.

숫자형 라벨을 가진 데이터프레임에서도 마찬가지입니다.

```python
df2 = pd.DataFrame({'값': [10, 20, 30]}, index=[1, 2, 3])

print(df2.loc[1:2]) # 결과: 인덱스 1과 2 모두 포함 (10, 20 출력)

```

---

## 4. 🤔 그렇다면 `loc`는 왜 마지막을 포함할까? (설계 철학)

파이썬의 다른 모든 기능(리스트 슬라이싱, `iloc`)은 끝 범위를 포함하지 않는데, 유독 `loc`만 마지막을 포함하는 이유는 **'라벨(Label)의 특성'** 때문입니다.

1. **라벨은 연속된 숫자가 아닐 수 있습니다.**
* 리스트의 인덱스는 `0, 1, 2, 3...`처럼 항상 1씩 증가하는 연속된 정수입니다. 그래서 `0:2`라고 하면 "0번, 1번을 뜻하고 2번 전에서 멈춘다"는 개념이 성립합니다.
* 하지만 `loc`에서 사용하는 라벨은 문자열(`'a', 'b', 'apple'`)이거나 날짜(`'2026-01-01', '2026-01-05'`)일 수 있습니다.


2. **날짜나 문자열 범위 지정의 직관성**
* 만약 날짜 데이터를 다룰 때 `df.loc['2026-01-01':'2026-01-05']`라고 검색했다고 가정해 봅시다.
* 만약 끝값을 포함하지 않는다면 사용자는 1월 5일 데이터를 얻기 위해 존재하지도 않는 임의의 다음 날짜나 헷갈리는 값을 입력해야 합니다.
* 사용자가 지정한 "이 이름부터 저 이름까지"라는 명확한 의미를 직관적으로 전달하기 위해, 판다스 개발진은 `loc`의 범위를 양쪽 모두 포함(Closed interval)하도록 설계했습니다.



---

## 5. 핵심 요약

* **`iloc[start:stop]`**: 정수 순번 기준. **마지막 `stop` 전까지만** 가져옴 (`stop` 미포함)
* **`loc[start:stop]`**: 라벨 이름 기준. **마지막 `stop` 라벨의 데이터까지 전부** 가져옴 (`stop` 포함)
