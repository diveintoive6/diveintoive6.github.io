## 1. 2차원 배열의 생성과 기본 프로퍼티

NumPy는 1차원뿐만 아니라 2차원, 3차원 이상의 다차원 배열(`ndarray`)을 효율적으로 다룰 수 있습니다. 리스트를 2차원 `ndarray`로 변환하고, 배열의 구조를 파악하는 주요 프로퍼티는 다음과 같습니다.

```python
import numpy as np

myarray = np.array([
    [98, 72, 80, 64],
    [88, 90, 80, 72],
    [92, 88, 82, 76]
])

print(myarray)
print("차원 크기(ndim):", myarray.ndim)
print("차원별 원소 수(shape):", myarray.shape)
print("원소의 데이터 타입(dtype):", myarray.dtype)

```

### 핵심 프로퍼티 설명

* **`ndim`**: 배열의 차원 크기를 반환합니다. (위 예시는 2차원이므로 `2`)
* **`shape`**: 차원별 원소의 개수를 **튜플(Tuple)** 형태로 반환합니다. (위 예시는 3행 4열이므로 `(3, 4)`)
* **`dtype`**: 배열에 포함된 원소의 데이터 타입을 반환합니다. ndarray는 **모든 원소가 동일한 자료형**이어야 하므로 하나의 타입만 출력됩니다.

> 💡 **Boolean 인덱싱과 차원 축소**: 불리언(Boolean) 타입 배열을 이용해 인덱싱을 수행하면, 조건에 맞는 원소들이 **1차원 배열로 반환**됩니다. 이를 통해 2차원 데이터를 1차원으로 쉽게 축소할 수 있습니다.

## 2. 그 외 다양한 특수 배열 생성 함수

필요에 따라 특정한 값으로 채워진 배열을 손쉽게 만들 수 있는 유용한 함수들입니다.

* **`np.zeros(shape)`**: 모든 원소가 `0`인 배열을 생성합니다.
* **`np.ones(shape)`**: 모든 원소가 `1`인 배열을 생성합니다.
* **`np.full(shape, value)`**: 지정한 `shape`의 배열을 특정 `value` 값으로 채웁니다.
```python
np.full((3, 4), 10)  # 3행 4열의 배열을 모두 10으로 채움

```


* **`np.eye(n)`**: $n \times n$ 크기의 단위 행렬(Identity Matrix)을 생성합니다. 대각선 방향은 `1`, 나머지는 `0`이 됩니다.

## 3. 랜덤 배열과 난수 시드(Random Seed)

데이터 분석, 머신러닝 모델 초기화, 시뮬레이션 등을 수행할 때 무작위 값을 갖는 배열이 자주 사용됩니다.

### 무작위 배열 생성 메서드

* **`np.random.rand(n)`**: `0`부터 `1` 사이의 균등한 범위에서 원소 수가 `n`개인 1차원 랜덤 배열 생성
* **`np.random.rand(rows, cols)`**: 파라미터가 2개인 경우 첫 번째는 행, 두 번째는 열을 의미하는 2차원 랜덤 배열 생성
* **`np.random.randint(low, high, size)`**: `low` 이상 `high` 미만 범위의 정수 랜덤값을 가지는 배열 생성 (`size`에 튜플을 주면 다차원 가능)
```python
np.random.randint(0, 9, (3, 4))  # 0~8 사이의 랜덤 정수로 채워진 3행 4열 배열

```



### 랜덤 시드(Random Seed)의 개념

컴퓨터의 난수는 진짜 무작위가 아니라 특정 알고리즘에 따라 생성되는 가짜 무작위값(Pseudo-random number)입니다.

* 랜덤 시드(Seed)는 그 규칙을 어디서부터 시작할지 정하는 '출발점 값'입니다.
* **동일한 시드**를 주면 항상 같은 난수 결과가 나오고, **다른 시드**를 주면 완전히 다른 결과가 나옵니다. 분석의 재현성을 위해 시드 고정은 필수입니다!

```python
# 정규분포를 따르는 랜덤값 생성 (평균=0, 표준편차=1, 크기=4행 3열)
np.random.seed(1234)  # 기준점 지정으로 결과 재현성 확보
random_arr = np.random.normal(0, 1, (4, 3))

```

> 📌 **정규분포(Normal Distribution)란?**
> 데이터가 평균을 중심으로 좌우 대칭인 종(bell) 모양 곡선을 이루는 형태입니다. 평균 근처에 데이터가 가장 많고 극단적인 값은 적게 나타납니다. 특히 평균=0, 표준편차=1인 **표준정규분포(Standard Normal Distribution)**는 데이터 표준화 및 확률적 모델링의 공통 기준 역할을 합니다.

## 4. 배열의 타입 변환 (`astype` 과 `asarray`)

ndarray는 동일한 데이터 타입만 허용하므로 필요에 따라 타입을 변환할 수 있습니다.

### 방법 1: `astype()` 함수 사용

기존 배열 객체의 메서드를 호출하여 새로운 타입의 배열로 변환합니다.

```python
arr1 = np.array([1, 2, 3])

# 실수형(float)으로 변환 (정수 1 -> 실수 1.0)
float_arr = arr1.astype('float')

# 문자열(str)로 변환 (정수 1 -> 문자열 '1')
str_arr = arr1.astype('str')

```

### 방법 2: `asarray()` 함수 사용

`np.asarray(원본배열, dtype='지정타입')` 형태로 사용하며, 호환 가능한 데이터 타입으로 변환할 때 유용합니다.

```python
# 10부터 19까지의 정수 배열 생성 (끝 값 20 미포함)
arr1 = np.arange(10, 20)

# 실수형으로 변환
arr2 = np.asarray(arr1, dtype='float')

# 문자열로 변환
arr3 = np.asarray(arr1, dtype='str')

```

> 💡 **참고**: `np.arange(start, stop)` 함수 역시 파이썬의 `range`처럼 **마지막 `stop` 값 직전까지만** 숫자를 생성한다는 점을 꼭 기억하세요!

## 5. `reshape()`을 이용한 차원 변환 및 확장/축소

`reshape()`은 배열의 데이터 원소 개수는 유지한 채, **차원과 형태(Shape)를 자유롭게 변경**할 수 있는 강력한 기능입니다.

### ① 1차원을 2차원으로 확장하기

```python
# 0부터 19까지 총 20개의 원소를 가진 1차원 배열
arr = np.arange(20)

# 4행 5열의 2차원 배열로 변환 (총 원소 개수 20개로 일치해야 함)
matrix = arr.reshape(4, 5)

```

### ② 차원 축소 및 `-1`의 활용

이미 다차원인 배열을 1차원으로 되돌리거나, 전체 원소 개수를 기반으로 차원을 자동 계산할 때 `-1`을 활용할 수 있습니다.

* **`-1`의 역할**: 전체 원소 개수를 기준으로 남은 차원 정보를 알아서 계산해 줍니다.
```python
# 12개의 원소를 가진 배열을 알아서 6행을 가진 2차원 배열로 변환
auto_matrix = arr12.reshape(-1, 2)

```



> ⚠️ **주의사항**: `reshape`을 할 때는 변환 전후의 **총 원소 개수가 완벽하게 일치**해야 합니다. 개수가 부족하거나 넘치면 에러가 발생하므로 전체 원소 수(Size)를 항상 염두에 두어야 합니다.

```
