## 1. HAVING 절과 중복 제거 (DISTINCT)

### HAVING 절의 사용
- **개념**: 집계 함수(`SUM`, `AVG`, `COUNT` 등)는 `WHERE`절에서 직접 사용할 수 없습니다. 따라서 **집계 결과에 대한 조건을 지정**할 때는 반드시 `HAVING`절을 사용해야 합니다.
- **특징**: `GROUP BY`절 없이 단독으로 사용할 수 없으며, 조건 검색을 위해 다양한 비교·논리·SQL 연산자(`=`, `!=`, `BETWEEN`, `IN`, `LIKE`, `IS NULL` 등)를 사용할 수 있습니다.

### 쿼리 실행 순서 및 전체 구문 구조
```sql
SELECT * | 컬럼이름 [[AS] 컬럼별칭]
FROM 테이블이름
[ WHERE 검색조건 ]
[ GROUP BY 기준컬럼1, 기준컬럼2, ... ]
[ HAVING 검색조건 ]
[ ORDER BY 정렬기준 ]
[ LIMIT 시작위치, 개수 ];

```

### 중복 행 제거 (DISTINCT)

* **용도**: 조회 결과에서 행 단위의 중복을 제거합니다.
* **특징**:
* `SELECT` 키워드 바로 뒤에 **단 한 번만** 명시할 수 있습니다.
* 특정 컬럼 이름 앞에만 국한되어 적용되는 것이 아니라, 조회되는 전체 컬럼 조합을 기준으로 중복을 제거합니다.
* 주로 데이터에 어떤 값들의 종류(카테고리)가 있는지 파악하고자 할 때 유용합니다.

## 2. 윈도우 함수 (Window Functions)

행과 행 간의 관계를 쉽게 정의하며, 각 행의 원래 내용을 유지하면서 정렬된 데이터의 특정 범위(윈도우) 안에서 순위, 합계, 평균 등의 집계 작업을 수행하는 함수입니다.

* **`OVER()` 절**: 윈도우 함수와 함께 사용되며, 이 안에서 어떻게 범위를 나눌지(`PARTITION BY`) 또는 어떤 순서로 정렬할지(`ORDER BY`)를 정의합니다.

### ① RANK() & DENSE_RANK()

* **`RANK()`**: 특정 열의 기준으로 순위를 계산합니다. 동일한 값이 있으면 **동일한 순위를 부여하고, 다음 순위는 건너뜁니다.** (예: 2등이 3명이면 다음 순위는 5등)
* **`DENSE_RANK()`**: 동일한 순위가 여러 개 있어도 **다음 순위를 건너뛰지 않고 이어갑니다.** (예: 2등이 3명이어도 다음 순위는 바로 3등)

### ② PARTITION BY (그룹 내 순위 매기기)

* `OVER()` 절 안에 `PARTITION BY`를 추가하면, 전체 데이터가 아닌 **지정된 그룹(파티션) 안에서만 순위를 계산**하도록 범위를 제한할 수 있습니다.
* `GROUP BY`처럼 결과를 하나의 행으로 압축하는 것이 아니라, **각 행의 개별 데이터와 함께 순위를 유지**하여 보여줍니다.

## 3. 데이터 무결성과 INSERT 문

### 데이터 무결성 (Data Integrity)

데이터가 틀리지 않고 논리적으로 맞도록 보장하는 안전장치입니다. 제약 조건을 위반하면 데이터베이스가 입·수정·삭제를 거부하고 에러를 발생시킵니다.

| 무결성 종류 | 설명 | 대표 제약 조건 | 예시 설명 |
| --- | --- | --- | --- |
| **엔티티 무결성** | 각 행(Row)은 고유해야 하며 식별 가능해야 함 | `PRIMARY KEY` (기본키) | 학번은 중복되거나 `NULL`일 수 없음 |
| **도메인 무결성** | 컬럼에 들어갈 값의 유형과 범위를 제한함 | `NOT NULL`, 데이터 타입, `ENUM` 등 | 나이는 0보다 커야 하며, `ENUM`은 지정된 값 중 하나만 허용 |
| **참조 무결성** | 특정 값은 반드시 다른 테이블에 존재하는 값이어야 함 | `FOREIGN KEY` (참조키) | 학생 테이블의 학과 ID는 학과 테이블에 반드시 존재해야 함 |

#### 🔑 기본키(Primary Key)의 특징

* 각 행을 유일하게 식별하며 테이블당 **하나만 설정**할 수 있습니다.
* 유일성(중복 불가)과 `NOT NULL`(필수 입력) 성격을 모두 가집니다.
* 단일 컬럼 또는 복합 컬럼으로 지정 가능하며, 보통 자동 증가(`AUTO_INCREMENT`) 속성과 함께 사용됩니다.

### 데이터 저장하기 (INSERT 문)

새로운 데이터를 테이블에 추가할 때 사용하는 명령어입니다.

```sql
INSERT INTO 테이블이름 (컬럼1, 컬럼2, ...) 
VALUES (값1, 값2, ...);

```

* **특징**: 컬럼 목록을 생략할 수 있으나 명시하는 것이 성능 및 유지보수에 좋습니다. 컬럼과 값의 개수, 순서가 완벽히 일치해야 합니다.
* **데이터 타입별 표현**: 문자열이나 날짜 형식은 작은따옴표(`'`)로 감싸고, 숫자는 그냥 작성합니다.

## 4. 실전 활용 예제 10선

### 예제 1: 집계 결과 조건 필터링 (`HAVING`)

부서별 평균 급여를 구할 때, 평균 급여가 400만 원 이상인 부서만 조회합니다.

```sql
SELECT department_id, AVG(salary) AS avg_salary
FROM employees
GROUP BY department_id
HAVING AVG(salary) >= 4000000;

```

### 예제 2: 중복 없는 카테고리 목록 조회 (`DISTINCT`)

주문 테이블(`orders`)에서 주문을 한 고객들의 고유한 아이디 목록만 추출합니다.

```sql
SELECT DISTINCT customer_id
FROM orders;

```

### 예제 3: 성적 순위 매기기 (`RANK`)

학생들의 시험 점수를 기준으로 전체 학생의 순위를 구합니다.

```sql
SELECT student_name, score,
       RANK() OVER (ORDER BY score DESC) AS overall_rank
FROM students;

```

### 예제 4: 밀집 순위 매기기 (`DENSE_RANK`)

공동 순위가 있더라도 다음 순위를 건너뛰지 않고 연이어 순위를 매깁니다.

```sql
SELECT student_name, score,
       DENSE_RANK() OVER (ORDER BY score DESC) AS dense_rank
FROM students;

```

### 예제 5: 부서 내 직원 급여 순위 매기기 (`PARTITION BY`)

전체가 아닌 각 부서(`department_id`) 내부에서 급여가 높은 순서대로 순위를 매깁니다.

```sql
SELECT department_id, employee_name, salary,
       RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dept_salary_rank
FROM employees;

```

### 예제 6: 기본 데이터 신규 삽입 (`INSERT`)

새로운 회원의 정보를 테이블에 안전하게 추가합니다.

```sql
INSERT INTO users (username, email, age, status)
VALUES ('홍길동', 'hong@example.com', 28, 'ACTIVE');

```

### 예제 7: ENUM 제약 조건이 포함된 데이터 삽입

엄격한 도메인 무결성(`ENUM` 타입)이 설정된 성별 컬럼에 올바른 값을 저장합니다.

```sql
INSERT INTO employees (emp_name, gender, hire_date)
VALUES ('김철수', 'M', '2026-03-12');

```

### 예제 8: 그룹화 조건과 정렬 조합 (`GROUP BY`, `HAVING`, `ORDER BY`)

상품 카테고리별 총 판매 금액이 100만 원 이상인 카테고리만 추려내어 매출액 순으로 정렬합니다.

```sql
SELECT category_id, SUM(sale_amount) AS total_sales
FROM sales
GROUP BY category_id
HAVING SUM(sale_amount) >= 1000000
ORDER BY total_sales DESC;

```

### 예제 9: 다중 컬럼 DISTINCT 활용

고객 아이디와 결제 수단 조합의 고유한 사용 패턴 종류를 파악합니다.

```sql
SELECT DISTINCT customer_id, payment_method
FROM payments;

```

### 예제 10: 윈도우 함수와 조건 필터링의 응용

부서별 급여 순위가 3위 이내인 우수 직원들만 추출합니다. (서브쿼리 활용)

```sql
SELECT *
FROM (
    SELECT department_id, employee_name, salary,
           RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) as rnk
    FROM employees
) ranked_emp
WHERE rnk <= 3;

```

## 5. 마무리 요약

* `HAVING` 절은 집계 함수 결과에 대한 필터링을 담당하며 반드시 `GROUP BY`와 함께 사용됩니다.
* `DISTINCT`는 데이터의 고유한 종류나 값의 조합을 파악하는 데 필수적입니다.
* `RANK`와 `DENSE_RANK`, 그리고 `PARTITION BY`를 활용한 윈도우 함수는 복잡한 순위 및 통계 분석 쿼리를 매우 우아하고 간결하게 해결해 줍니다.
* 데이터 무결성 제약 조건(`PRIMARY KEY`, `ENUM` 등)을 철저히 설계해야 안전한 데이터베이스 운영이 가능합니다.
